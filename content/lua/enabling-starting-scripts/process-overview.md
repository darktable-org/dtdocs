## darktable version 5.6 and after

Darktable (starting at version 5.6) comes with several built-in and contributed scripts for performing various actions.

However, to use a supplied script, one first must enable it. As an example we will use the contributed script "rename-images".

1. [Find the location of your desired script](finding); in our example we need to find the folder containing the "rename-images" script.
1. [Start the script](starting).

## darktable versions before 5.6

If you are using a version of darktable before 5.6, see the [section on writing Lua scripts](../writing-lua-scripts) for how to enable scripts in that older version of darktable.
