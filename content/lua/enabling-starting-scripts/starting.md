Once you have [found the folder containing a script](finding), 
such as "rename-images", use the following steps to start it

1. Click (once) on ![the grayed-out start/stop icon](grayed-out-on-off-button.png#icon) to the left of the name of the script, which turns the script on.
1. The ![icon](on-off-button-on.png#icon) should turn bold (whiter) to indicate that the script is on and the script's user interface (if it has one) will appear in a panel in the appropriate view.
1. In this example, the ![interface for the script](rename-images-UI-unopened.png#w50) user interface for the script appears in the right panel of the lighttable view. (You can move it to a different place in one of the panels using the ![hamburger icon](hamburger-icon.png#icon) icon with the three horizontal lines.)
1. To open that user interface, click (once) on the right-facing arrowhead at the left side of the user interface to expand it. Then interact with the script as described in [its documentation](https://docs.darktable.org/lua/stable/lua.scripts.manual/scripts/).

These actions need to be repeated for each script you wish to use.
