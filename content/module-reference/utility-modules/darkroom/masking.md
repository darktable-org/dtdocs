Show the [mask panel](../../../darkroom/masking-and-blending/masks/mask-panel.md) of the focused processing module in the left-hand panel.

This module is only shown when _panel position_ is set to _utility module, left panel_ in the [mask options](../../../darkroom/masking-and-blending/masks/mask-panel.md#mask-options). In this position, the mask panel is removed from the bottom of each processing module and shown here instead, for whichever processing module has focus. This keeps the processing modules short, and keeps the mask in view while you move between modules.

The module's header holds the mask on/off toggle (right-click it for the mask options) and a reset button, which resets the mask of the focused module. The other [header controls](../../../darkroom/masking-and-blending/masks/mask-panel.md#panel-header) of the mask panel are in a row below the header. If no module has focus, or if the focused module does not support masks, the module says so.

See [masks](../../../darkroom/masking-and-blending/masks/overview.md) for how to build a mask, and [the mask panel](../../../darkroom/masking-and-blending/masks/mask-panel.md) for a description of its controls.

---

**Note:** In darktable 5.6 and earlier, this position in the left-hand panel was occupied by the _mask manager_, which listed the drawn shapes of the image and allowed them to be grouped and combined. The mask manager has been removed: all of its functions are now in the mask panel. See [migrating from classic masks](../../../darkroom/masking-and-blending/masks/migration.md).
