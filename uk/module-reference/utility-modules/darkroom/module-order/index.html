Порядок застосування модулів

Змінити порядок модулів обробки у темній кімнаті за допомогою пресетів.

Під час обробки зображення активні модулі застосовуються в певному порядку, який показано на правій панелі режиму темної кімнати. Цей модуль надає інформацію про поточне впорядкування модулів обробки в конвеєрі. Назва поточного вибраного пресета відображається в заголовку модуля (або “власний”, якщо користувач вручну змінив порядок). Для вибору доступні наступні пресети.

v5.0 RAW
Це порядок модулів за замовчуванням для робочого процесу обробки raw на основі сцен у Darktable 5.0 та пізніших версіях.
v5.0 JPEG
Це порядок модулів за замовчуванням для обробки JPEG у Darktable 5.0 та пізніших версіях
v3.0 RAW
Це порядок модулів за замовчуванням для робочого процесу обробки raw на основі сцен між Darktable 3.0 та Darktable 4.8.
v3.0 JPEG
Це порядок модулів за замовчуванням для обробки JPEG між Darktable 3.0 та Darktable 4.8.
Застарілий
Цей порядок модулів використовується для застарілого робочого процесу на основі відображення. Ви також побачите цей порядок для всіх зображень, які ви раніше редагували у Darktable до версії 3.0.
Власний
Користувач вручну змінив порядок модулів.

Примітка: зміна порядку модулів у конвеєрі не є косметичною зміною презентації графічного інтерфейсу користувача – це має реальні наслідки для того, як буде оброблено зображення. Будь ласка, не змінюйте порядок модулів, хіба що ви маєте конкретну технічну причину і ви розумієте, чому це потрібно з точки зору обробки зображень.

Для отримання додаткової інформації про зміну порядку модулів, зверніться до конвеєр обробки та порядок модулів.
