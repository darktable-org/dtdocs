              línea de tiempo

              Vea sus imágenes ordenadas por el día/hora en que fueron tomadas.

              En la vista del administrador de archivos de la mesa de luz, puede mostrar/ocultar el módulo de línea de tiempo en el panel inferior con el atajo Ctrl+F.

              Dentro de la línea de tiempo, puede mostrar las fechas anteriores y siguientes desplazando el ratón; Ctrl+desplazamiento para acercar/alejar.

              También puede usar la línea de tiempo para seleccionar imágenes por rango de fechas haciendo clic y arrastrando el ratón.
