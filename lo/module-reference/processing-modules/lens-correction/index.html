      ແກ້ໄຂ (ຫຼື ຈຳລອງ) ຄວາມບິດເບືອນຂອງເລນ, ຄວາມຜິດພ້ຽນຂອງສີ (TCA) ແລະ ຂອບມືດ (vignetting) ໂດຍອັດຕະໂນມັດ.

      ທ່ານສາມາດເລືອກໃຊ້ຂໍ້ມູນການແກ້ໄຂເລນທີ່ຝັງຢູ່ໃນໄຟລ໌ RAW (ຖ້າມີ/ຮອງຮັບ) ຫຼື ຂໍ້ມູນການແກ້ໄຂ ທີ່ສະໜອງໃຫ້ໂດຍ Lensfun library ຈາກພາຍນອກ.

      ນອກຈາກນີ້ຍັງມີການຄວບຄຸມເພີ່ມເຕີມສຳລັບການແກ້ໄຂຂອບມືດດ້ວຍຕົນເອງ ໃນກໍລະນີທີ່ໂປຣໄຟລ໌ເລນຂອງທ່ານ ບໍ່ພຽງພໍ ຫຼື ບໍ່ມີ.

      ໝາຍເຫດ: ຖ້າເປີດໃຊ້ການແກ້ໄຂ TCA ໃນໂມດູນນີ້, ການໃຊ້ raw chromatic aberrations ຮ່ວມດ້ວຍອາດເຮັດໃຫ້ເກີດຄວາມຜິດພ້ຽນຈາກການແກ້ໄຂທີ່ຫຼາຍເກີນໄປ.

      #ຂໍ້ມູນການແກ້ໄຂ Lensfun

      ຖ້າ Lensfun library ໃນລະບົບຂອງທ່ານບໍ່ມີໂປຣໄຟລ໌ການແກ້ໄຂສຳລັບການລວມກັນຂອງກ້ອງ/ເລນທີ່ກວດພົບອັດຕະໂນມັດ, ການຄວບຄຸມສຳລັບຄ່າໂຟໂຕເມທຣິກສາມຢ່າງ (ຂ້າງລຸ່ມນີ້) ຈະຖືກແທນທີ່ດ້ວຍຂໍ້ຄວາມເຕືອນ. ທ່ານສາມາດລອງຄົ້ນຫາ ໂປຣໄຟລ໌ທີ່ຖືກຕ້ອງດ້ວຍຕົນເອງໃນເມນູ.

      ຖ້າເລນຂອງທ່ານມີຢູ່ໃນລາຍການແຕ່ລະບົບບໍ່ສາມາດລະບຸໄດ້ຢ່າງຖືກຕ້ອງ, ອາດຈະຕ້ອງມີການປັບແຕ່ງໃນໂປຣແກຣມ exiv2 (ເບິ່ງລາຍລະອຽດທີ່ ໂພສນີ້). ໝາຍເຫດ: ທ່ານອາດຈະຕ້ອງ ນຳເຂົ້າຮູບພາບຄືນໃໝ່ຫຼັງຈາກປັບແຕ່ງແລ້ວ ເພາະຊື່ເລນຈະຖືກດຶງມາໃນລະຫວ່າງການນຳເຂົ້າ.

      ໂດຍປົກກະຕິ, ມີພຽງແຕ່ເລນທີ່ເຂົ້າກັນໄດ້ໂດຍກົງກັບເມົາທ໌ (mount) ຂອງກ້ອງທ່ານເທົ່ານັ້ນທີ່ຈະຖືກສະແດງ ແລະ ລະບຸອັດຕະໂນມັດ. ຖ້າທ່ານໃຊ້ເລນຕ່າງເມົາທ໌ຜ່ານອະແດັບເຕີ (ເຊັ່ນ: ເລນ Canon EF ໃສ່ກ້ອງ Nikon Z), ທ່ານຕ້ອງໃຊ້ເຄື່ອງມື lensfun-add-adapter ເພື່ອເປີດໃຊ້ງານເລນເຫຼົ່ານັ້ນ.

      ຖ້າທ່ານຫາເລນຂອງທ່ານບໍ່ພົບ, ໃຫ້ກວດເບິ່ງໃນ ລາຍການເລນທີ່ຮອງຮັບ ແລະ ລອງໃຊ້ເຄື່ອງມື lensfun-update-data. ຖ້າຍັງບໍ່ມີໂປຣໄຟລ໌ທີ່ກົງກັນ, ທ່ານສາມາດໃຊ້ ບໍລິການປັບທຽບເລນ ໂດຍ Torsten Bronger ຫຼື ໄປທີ່ ໂຄງການ Lensfun ເພື່ອຮຽນຮູ້ ວິທີສ້າງຄ່າການແກ້ໄຂເອງ. ຢ່າລືມແບ່ງປັນໂປຣໄຟລ໌ຂອງທ່ານໃຫ້ກັບທີມງານ Lensfun!

      #ສ່ວນຄວບຄຸມໂມດູນ

      ວິທີການແກ້ໄຂ
      ເລືອກວິທີທີ່ຈະໃຊ້ແກ້ໄຂຄວາມບິດເບືອນ. ການຄວບຄຸມເພີ່ມເຕີມຈະສະແດງຂຶ້ນຕາມຕົວເລືອກທີ່ເລືອກ:
      • “Lensfun database”: ໃຊ້ການແກ້ໄຂຈາກຖານຂໍ້ມູນຂອງໂຄງການ Lensfun.
      • “embedded metadata”: ໃຊ້ການແກ້ໄຂທີ່ຝັງຢູ່ໃນຂໍ້ມູນ metadata ຂອງໄຟລ໌ RAW. (ໃຊ້ໄດ້ຖ້າມີຂໍ້ມູນຮອງຮັບ).
      • “only manual vignette”: ບໍ່ໃຊ້ການແກ້ໄຂອັດຕະໂນມັດ ແຕ່ໃຫ້ປັບຂອບມືດດ້ວຍຕົນເອງ.
      ການແກ້ໄຂ
      ເລືອກວ່າຈະໃຊ້ການແກ້ໄຂໃດ (ຄວາມບິດເບືອນ, TCA, ຂອບມືດ). ປ່ຽນຈາກຄ່າ “ທັງໝົດ (all)” ຖ້າກ້ອງຂອງທ່ານໄດ້ແກ້ໄຂບາງຢ່າງມາແລ້ວ ຫຼື ທ່ານຕ້ອງການໄປແກ້ໄຂໃນໂປຣແກຣມອື່ນ.
      ການແກ້ໄຂທີ່ສຳເລັດ
      ບາງຄັ້ງ ສຳລັບການລວມກັນຂອງກ້ອງ/ເລນບາງແບບ, ອາດຈະຮອງຮັບການແກ້ໄຂພຽງບາງຢ່າງເທົ່ານັ້ນ. ກ່ອງຂໍ້ຄວາມນີ້ຈະສະແດງຢູ່ລຸ່ມສຸດເພື່ອບອກວ່າໄດ້ໃຊ້ການແກ້ໄຂໃດແດ່ກັບຮູບພາບ.
      ສະແດງເສັ້ນນຳທາງ
      ໝາຍຕິກໃສ່ຫ້ອງລຸ່ມສຸດເພື່ອສະແດງເສັ້ນນຳທາງເມື່ອເປີດໃຊ້ໂມດູນ. ຄລິກໄອຄອນທາງຂວາເພື່ອຄວບຄຸມ ຄຸນສົມບັດຂອງເສັ້ນນຳທາງ. ເບິ່ງ ເສັ້ນນຳທາງ ແລະ ສິ່ງວາງຊ້ອນ ສຳລັບລາຍລະອຽດ.

      #ການຄວບຄຸມ Lensfun

      ການຄວບຄຸມຕໍ່ໄປນີ້ມີໄວ້ສຳລັບວິທີການແກ້ໄຂແບບ “Lensfun” ເທົ່ານັ້ນ:

      ກ້ອງ
      ຍີ່ຫໍ້ ແລະ ລຸ້ນຂອງກ້ອງທີ່ລະບຸຈາກຂໍ້ມູນ Exif. ທ່ານສາມາດປ່ຽນເອງໄດ້ໂດຍເລືອກຈາກເມນູ. ມີພຽງແຕ່ເລນທີ່ມີໂປຣໄຟລ໌ການແກ້ໄຂທີ່ກົງກັບກ້ອງທີ່ເລືອກເທົ່ານັ້ນທີ່ຈະຖືກສະແດງ.
      ເລນ
      ຍີ່ຫໍ້ ແລະ ລຸ້ນຂອງເລນທີ່ລະບຸຈາກຂໍ້ມູນ Exif. ທ່ານສາມາດປ່ຽນເອງໄດ້ໂດຍເລືອກຈາກເມນູ. ສ່ວນຫຼາຍແມ່ນຈຳເປັນສຳລັບເລນມືໝຸນ (mechanical) ຫຼື ເລນຄ່າຍອິດສະຫຼະ (third party).
      ຄ່າໂຟໂຕເມທຣິກ (ໄລຍະໂຟກັດ, ຮູຮັບແສງ, ໄລຍະຫ່າງໂຟກັດ)
      ການແກ້ໄຂເລນຂຶ້ນຢູ່ກັບຄ່າເຫຼົ່ານີ້ທີ່ອ່ານມາຈາກ Exif: ໄລຍະໂຟກັດ (ສຳລັບຄວາມບິດເບືອນ, TCA, ຂອບມືດ), ຮູຮັບແສງ (ສຳລັບ TCA, ຂອບມືດ) ແລະ ໄລຍະຫ່າງໂຟກັດ (ສຳລັບຂອບມືດ). ກ້ອງຫຼາຍລຸ້ນບໍ່ໄດ້ບັນທຶກໄລຍະຫ່າງໂຟກັດ ໃນ Exif, ຊຶ່ງທ່ານອາດຈະຕ້ອງຕັ້ງຄ່າເອງ.

      ທ່ານສາມາດປ່ຽນຄ່າທັງໝົດທີ່ເລືອກໂດຍອັດຕະໂນມັດໄດ້. ໂດຍເລືອກຈາກຄ່າທີ່ມີໃຫ້ ຫຼື ພິມຄ່າຂອງທ່ານເອງລົງໄປ.

      ເລຂາຄະນິດເປົ້າໝາຍ (target geometry)
      ນອກຈາກການແກ້ໄຂຂໍ້ບົກພ່ອງຂອງເລນແລ້ວ, ໂມດູນນີ້ຍັງສາມາດປ່ຽນປະເພດການສາຍພາບ (projection type) ຂອງຮູບພາບຂອງທ່ານໄດ້. ໃຫ້ຕັ້ງຄ່າໃນກ່ອງເລືອກນີ້ເປັນປະເພດການສາຍພາບທີ່ຕ້ອງການ (ເຊັ່ນ: “rectilinear”, “fisheye”, “panoramic”, “equirectangular”, “orthographic”, “stereographic”, “equisolid angle”, “Thoby fisheye”). ເພື່ອແກ້ໄຂອັດຕາສ່ວນພາບຂອງເລນອະນາມໍຟິກ (anamorphic lens), ໃຫ້ໃຊ້ໂມດູນ ໝູນ ແລະ ເປສເປັກທີບ.
      ມາດຕາສ່ວນ (scale)
      ປັບອັດຕາສ່ວນຂະຫຍາຍຂອງຮູບເພື່ອຫຼີກລ່ຽງຂອບດຳ. ກົດປຸ່ມປັບອັດຕະໂນມັດ (ທາງຂວາຂອງແຖບເລື່ອນ) ເພື່ອໃຫ້ darktable ຊອກຫາຂະໜາດທີ່ເໝາະສົມທີ່ສຸດ.
      ໂໝດ
      ຄ່າເລີ່ມຕົ້ນແມ່ນເພື່ອ ແກ້ໄຂ ຂໍ້ບົກພ່ອງເລນ. ປ່ຽນເປັນ “distort” ເພື່ອ ຈຳລອງ ຂໍ້ບົກພ່ອງ/ຄວາມບິດເບືອນ ຂອງເລນສະເພາະ (ຜົນລັບແບບປີ້ນ).
      ກຳນົດ TCA ເອງ
      ໝາຍຕິກບ່ອນນີ້ເພື່ອແກ້ໄຂຄ່າ TCA ເອງ. ມັນຈະສະແດງຄ່າ TCA ສີແດງ ແລະ ສີຟ້າໃຫ້ປັບ. ຫາກເອົາເຄື່ອງໝາຍອອກ ຈະກັບໄປໃຊ້ການແກ້ໄຂອັດຕະໂນມັດ.
      TCA ສີແດງ; TCA ສີຟ້າ
      ປັບແຕ່ງຄ່າການແກ້ໄຂ TCA. ທ່ານສາມາດໃຊ້ແຖບເລື່ອນນີ້ຫາກໂປຣໄຟລ໌ເລນບໍ່ມີຂໍ້ມູນການແກ້ໄຂ TCA. ໃຫ້ສັງເກດຂອບສີທີ່ເກີດຂຶ້ນຢູ່ບໍລິເວນທີ່ມີຄອນທຣາສສູງ ແລ້ວປັບຄ່າເພື່ອຫຼຸດຂອບສີເຫຼົ່ານັ້ນ.

      ໝາຍເຫດ: ການແກ້ໄຂ TCA ຈະບໍ່ຖືກໃຊ້ກັບຮູບພາບທີ່ຖືກລະບຸວ່າເປັນພາບຂາວດຳ (monochrome) (ເບິ່ງ ການລ້າງຮູບຂາວດຳ ສຳລັບຂໍ້ມູນເພີ່ມເຕີມ).

      ໝາຍເຫດ: ໂມດູນການແກ້ໄຂເລນຈະຕື່ມຂໍ້ມູນທີ່ຫາຍໄປຢູ່ຂອບພາບໂດຍການເຮັດຊ້ຳພິກເຊລຂອບ. ຫາກມີການແກ້ໄຂຫຼາຍ, ສິ່ງນີ້ອາດຈະເຫັນໄດ້ຊັດເຈນ (ໂດຍສະເພາະໃນຮູບທີ່ມີນອຍສ໌ຫຼາຍ). ໃຫ້ຕັດຂອບພາບ (crop) ຫາກຈຳເປັນ.

      #ການຄວບຄຸມ metadata ທີ່ຝັງມາ

      ການຄວບຄຸມຕໍ່ໄປນີ້ມີໄວ້ສຳລັບວິທີການແກ້ໄຂແບບ “embedded metadata” ເທົ່ານັ້ນ:

      ໃຊ້ສູດຄຳນວນຫຼ້າສຸດ
      ສ່ວນນີ້ຈະສະແດງຂຶ້ນສຳລັບຮູບທີ່ໃຊ້ສູດຄຳນວນການແກ້ໄຂແບບເກົ່າ. ໝາຍຕິກບ່ອນນີ້ເພື່ອປ່ຽນເປັນສູດຄຳນວນໃໝ່ (ການປ່ຽນແປງນີ້ບໍ່ສາມາດຍ້ອນກັບໄດ້).

      ການຄວບຄຸມຕໍ່ໄປນີ້ສາມາດສະແດງໄດ້ໂດຍການຄລິກປຸ່ມ “ປັບແຕ່ງລະອຽດ (fine-tuning)”:

      ຄວາມບິດເບືອນ (distortion)
      ປັບແຕ່ງລະອຽດການແກ້ໄຂຄວາມບິດເບືອນ / ຄວາມຜິດພ້ຽນຂອງສີ.
      ຂອບມືດ (vignetting)
      ປັບແຕ່ງລະອຽດການແກ້ໄຂຂອບມືດ.
      TCA ສີແດງ
      ປັບແຕ່ງລະອຽດການແກ້ໄຂຄວາມຜິດພ້ຽນຂອງສີແດງ.
      TCA ສີຟ້າ
      ປັບແຕ່ງລະອຽດການແກ້ໄຂຄວາມຜິດພ້ຽນຂອງສີຟ້າ.
      ມາດຕາສ່ວນພາບ
      ກຳນົດການຂະຫຍາຍພາບເອງ.

      #ການແກ້ໄຂຂອບມືດດ້ວຍຕົນເອງ

      ການແກ້ໄຂຂອບມືດແບບສົມບູນອາດຈະບໍ່ມີ ຫຼື ບໍ່ພຽງພໍສຳລັບເລນຫຼາຍໆແບບ, ບໍ່ວ່າຈະໃຊ້ຂໍ້ມູນ metadata ຫຼື ຖານຂໍ້ມູນ Lensfun. ຄລິກປຸ່ມ “manual vignetting correction” ເພື່ອປັບແຕ່ງເພີ່ມເຕີມ ຜ່ານການຄວບຄຸມດັ່ງຕໍ່ໄປນີ້.

      ຄວາມແຮງ (strength)
      ຄວາມແຮງໂດຍລວມຂອງເອັບເຟັກ.
      ລັດສະໝີ (radius)
      ພື້ນທີ່ຂອງຮູບພາບທີ່ບໍ່ຖືກປ່ຽນແປງໂດຍການແກ້ໄຂ.
      ຄວາມຊັນ (steepness)
      ຄວາມຊັນຂອງເອັບເຟັກການແກ້ໄຂທີ່ຢູ່ນອກລັດສະໝີ.

      ທ່ານສາມາດເບິ່ງຜົນຂອງການແກ້ໄຂໄດ້ໂດຍການຄລິກທີ່ປຸ່ມ ໜ້າກາກ (mask) ທາງຂ້າງແຖບເລື່ອນຄວາມແຮງ.

      #manual distortion correction

      Manual distortion corrections are not natively supported.

      A workaround can help to make manual corrections:

      • Switch correction method to Lensfun database, then pick the “generic” profiles, choose a “generic” rectilinear lens (e.g. “Generic, Crop-factor 1.0 (Full Frame)”) and set target geometry to orthographic.
      • Use mode to set the direction of the applied effect (correct for barrel; distort for pincushion) and the mm adjustment to tune the magnitude of the correction.
      • Use the scale slider to make the image fit and if need be fine tune with the target geometry.
      • If you find a good fit for your lens (or the respective zoom range of a lens with variable focal length) you can then save the settings as a preset and set it up to auto apply if appropriate exif metadata is available.
