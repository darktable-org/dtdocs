ຊິກມອຍ (sigmoid)

ຂໍ້ມູນທາງເຕັກນິກ
ລາຍລະອຽດ
ນຳໃຊ້ການແປງມຸມເບິ່ງເພື່ອໃຫ້ພາບສາມາດສະແດງຜົນເທິງໜ້າຈໍ ຫຼື ການພິມ ໂດຍໃຊ້ເສັ້ນໂຄ້ງໂທນສີທີ່ແຂງແຮງ ແລະ ນຸ້ມນວນ ພ້ອມທັງມີວິທີການຮັກສາສີໃຫ້ເລືອກ.
ຈຸດປະສົງ
ເພື່ອແກ້ໄຂ ແລະ ສ້າງສັນ.
ຂໍ້ມູນເຂົ້າ
linear, RGB, scene-referred.
ການປະມວນຜົນ
non-linear, RGB.
ຂໍ້ມູນອອກ
linear, RGB, display-referred.

ຈັດວາງຊ່ວງໂທນສີຂອງພາບໃໝ່ໂດຍໃຊ້ເສັ້ນໂຄ້ງລັອກ-ໂລຈິສຕິກທົ່ວໄປ (generalized log-logistic curve) ທີ່ໄດ້ຮັບການປັບແຕ່ງ.

ໂມດູນນີ້ສາມາດໃຊ້ເພື່ອຂະຫຍາຍ ຫຼື ບີບອັດໄດນາມິກເຣນຈ໌ (dynamic range) ຂອງສາກໃຫ້ເໝາະສົມກັບໄດນາມິກເຣນຈ໌ຂອງການສະແດງຜົນ.

ໝາຍເຫດ: ໂມດູນທີ່ວາງໄວ້ກ່ອນ sigmoid ໃນລຳດັບການປະມວນຜົນຈະເຮັດວຽກໃນພື້ນທີ່ ອ້າງອີງຕາມສາກ (scene-referred). ສ່ວນໂມດູນຫຼັງ sigmoid ຈະເຮັດວຽກໃນພື້ນທີ່ ອ້າງອີງຕາມການສະແດງຜົນ (display-referred).

ເຈົ້າສາມາດເປີດໃຊ້ໂມດູນນີ້ໂດຍອັດຕະໂນມັດໃນຮູບໃໝ່ໂດຍການຕັ້ງຄ່າ ການຕັ້ງຄ່າ > ການປະມວນຜົນ > ນຳໃຊ້ workflow pixel ເລີ່ມຕົ້ນໂດຍອັດຕະໂນມັດ ເປັນ ‘scene-referred (sigmoid)’ (ນີ້ແມ່ນຄ່າເລີ່ມຕົ້ນສຳລັບການຕິດຕັ້ງໃໝ່).

🔗ການນຳໃຊ້

ກະລຸນາສັງເກດຄຳແນະນຳຕໍ່ໄປນີ້ໃນຂະນະທີ່ນຳໃຊ້ໂມດູນນີ້ໃນຂະບວນການເຮັດວຽກຂອງທ່ານ:

ໃຊ້ການແປງການສະແດງຜົນພຽງອັນດຽວ
ຫ້າມໃຊ້ sigmoid ຮ່ວມກັບໂມດູນການແປງການສະແດງຜົນອື່ນໆ (ເຊັ່ນ filmic rgb, AgX ຫຼື base curve).
ປັບໂທນສີປານກາງກ່ອນ
ເສັ້ນໂຄ້ງຊິກມອຍຈະໝຸນອ້ອມຄ່າສີເທີົາປານກາງ. ກ່ອນຈະໃຊ້ sigmoid, ເຈົ້າຄວນໃຊ້ໂມດູນ ການເປີດຮັບແສງ (exposure) ເພື່ອປັບໂທນສີປານກາງໃຫ້ໄດ້ຕາມທີ່ຕ້ອງການກ່ອນ.
ນ້ອຍແຕ່ຫຼາຍ
ເຈົ້າຄວນພະຍາຍາມປະມວນຜົນສ່ວນໃຫຍ່ໂດຍໃຊ້ໂມດູນໃນສ່ວນ scene-referred ຂອງ pixelpipe ແລະ ບໍ່ຄວນເພິ່ງພາພຽງແຕ່ໂມດູນການແປງການສະແດງຜົນ (sigmoid, filmic rgb, base curve) ເພື່ອເຮັດວຽກທັງໝົດ.
ຮັກສາໂທນສີຕາມຄວາມມັກ
ໂມດູນນີ້ມີຫຼາຍວິທີໃນການຮັກສາໂທນສີ. ແນະນຳໃຫ້ໃຊ້ໂໝດ “per channel” ແລະ ປັບການຮັກສາໂທນສີຕາມຄວາມມັກໃນແຕ່ລະພາບ. ພາບຕາເວັນຕົກດິນ ແລະ ໄຟ ແມ່ນສອງຕົວຢ່າງທີ່ຜູ້ໃຊ້ມັກຈະຫຼຸດການຮັກສາໂທນສີລົງເພື່ອໃຫ້ໄດ້ພາບທີ່ເບິ່ງ “ຮ້ອນແຮງ” ຂຶ້ນ.
ຄວບຄຸມຄ່າ skew ໃຫ້ເໝາະສົມ
ສຳລັບພາບເຊັ່ນ ພາບຄົນ (portraits), ທາງທີ່ດີຄວນຫຼີກລ່ຽງການໃຊ້ຄ່າ skew ທີ່ສູງກວ່າສູນ. ວິທີນີ້ຈະຊ່ວຍຫຼີກລ່ຽງການປ່ຽນຜ່ານທີ່ແຂງເກີນໄປໃນໂທນສີຜິວ. ນີ້ແມ່ນສິ່ງສຳຄັນເປັນພິເສດເມື່ອບໍ່ໄດ້ເປີດໃຊ້ການຮັກສາໂທນສີ, ເພາະຄ່າ skew ຈະສົ່ງຜົນຕໍ່ທິດທາງສີຂອງໂທນສີຜິວນຳ.

🔗ສ່ວນຄວບຄຸມໂມດູນ

ຄອນທຣາສ
ປັບຄວາມແຮງຂອງການບີບອັດໂດຍທີ່ບໍ່ປ່ຽນແປງຄ່າສີເທີົາປານກາງ. ຄ່າທີ່ສູງຂຶ້ນຈະຕ້ອງການການເປີດຮັບແສງທີ່ຕ່ຳລົງເພື່ອໃຫ້ຮອດຈຸດສີຂາວຂອງການສະແດງຜົນ, ແລະ ສ່ວນເງົາຈະມືດລົງ. ຄອນທຣາສທີ່ຕ່ຳລົງຈະສາມາດສະແດງໄດນາມິກເຣນຈ໌ໄດ້ກວ້າງຂຶ້ນ.
skew (ຄວາມອຽງ)
ປັບການບີບອັດໃຫ້ອຽງໄປທາງສ່ວນເງົາ ຫຼື ສ່ວນສະຫວ່າງ. Skew ສາມາດໃຊ້ເພື່ອຖ່າຍໂອນຄອນທຣາສບາງສ່ວນຈາກເງົາໄປຫາສ່ວນສະຫວ່າງ ຫຼື ໃນທາງກັບກັນ ໂດຍບໍ່ປ່ຽນແປງປະລິມານຄອນທຣາສທີ່ສີເທີົາປານກາງ. ຄ່າ skew ບວກຈະເຮັດໃຫ້ເງົາແປ (flattens) ແລະ ບີບອັດສ່ວນສະຫວ່າງ. ຄ່າ skew ລົບຈະເຮັດໃຫ້ເງົາມືດຂຶ້ນ ແລະ ສ່ວນສະຫວ່າງມົວລົງ.
ການປະມວນຜົນສີ
ໂໝດທີ່ໃຊ້ເພື່ອຈັບຄູ່ຄ່າພິກເຊລຈາກພື້ນທີ່ສາກ (scene) ໄປຫາພື້ນທີ່ການສະແດງຜົນ (display).
  • ໂໝດ ແຍກຕາມຊ່ອງສັນຍານ ຈະນຳໃຊ້ເສັ້ນໂຄ້ງຊິກມອຍ (sigmoid) ກັບແຕ່ລະຊ່ອງສັນຍານ RGB ແຍກກັນ, ເຊິ່ງສົ່ງຜົນກະທົບຕໍ່ຄວາມສະຫວ່າງ, ຄວາມສົດຂອງສີ, ແລະ ໂທນສີ. ທ່ານສາມາດເລືອກຮັກສາໂທນສີໄດ້ໂດຍໃຊ້ຕົວເລືອກ ຮັກສາໂທນສີ (ຢູ່ລຸ່ມນີ້). ໂໝດນີ້ສອດຄ່ອງກັບການເຮັດວຽກຂອງຊັ້ນສີໃນຟິມອານາລັອກ ແລະ ສາມາດຈັດການການຜ່ອນລະດັບແສງໄປຫາສ່ວນທີ່ສະຫວ່າງຫຼາຍໄດ້ດີຫຼາຍ.
  • ອັດຕາສ່ວນ RGB ແມ່ນຄ້າຍຄືກັນກັບ ຮັກສາສີ ໃນ filmic rgb. ມັນຈະຈັບຄູ່ກຸ່ມສາມສີ RGB ຢ່າງເປັນເອກະພາບໂດຍໃຊ້ເສັ້ນໂຄ້ງຊິກມອຍ, ເຊິ່ງຈະຊ່ວຍຮັກສາສີໃນສະເປກຕຣັມຂອງພິກເຊລໄວ້. ພິກເຊລທີ່ມີສີສັນສົດໃສ ແລະ ສະຫວ່າງ ຈະຖືກຫຼຸດຄວາມອີ່ມຕົວຂອງສີລົງຕາມເສັ້ນສະເປກຕຣັມ ເພື່ອບໍ່ໃຫ້ມັນຫຼຸດອອກນອກຂອບເຂດສີຂອງຈໍສະແດງຜົນ.
ຮັກສາໂທນສີ (ສະເພາະໂໝດ per channel ເທົ່ານັ້ນ)
ເລືອກວ່າຈະຮັກສາໂທນສີຫຼາຍປານໃດ – 100% ຈະຮັກສາໂທນສີສະເປກຕຣັມຂອງພາບ (ຄືກັນກັບການໃຊ້ໂໝດ “rgb ratio”); 0% ຈະໃຊ້ໂໝດ per-channel ທີ່ມີການບິດເບືອນໂທນສີຢ່າງແຮງ (ເບິ່ງດ້ານລຸ່ມ). ຄ່າການຮັກສາໂທນສີທີ່ເໝາະສົມມັກຈະຢູ່ລະຫວ່າງກາງຂອງສອງຄ່ານີ້.
ສີທັງໝົດທີ່ຢູ່ລະຫວ່າງສີພື້ນຖານ (ແດງ, ຂຽວ, ຟ້າ) ຈະເບນເຂົ້າຫາສີຂັ້ນສອງທີ່ໃກ້ທີ່ສຸດ (ເຫຼືອງ, ມ່ວງແດງ, ຟ້າອ່ອນ). ເອັບເຟັກ per channel hue skew ຈະເຮັດໃຫ້ຕາເວັນຕົກດິນ ແລະ ໄຟເບິ່ງເປັນສີເຫຼືອງ, ໄຟສີຟ້າເບິ່ງເປັນສີມ່ວງແດງ, ແລະ ທ້ອງຟ້າເປັນສີຟ້າອ່ອນ. ການບິດເບືອນຈະແຮງຂຶ້ນສຳລັບພິກເຊວທີ່ສະຫວ່າງ ແລະ ມີຄວາມອີ່ມຕົວສູງ.
ເປົ້າໝາຍສີດຳ
ຂີດຈຳກັດຕ່ຳສຸດທີ່ເສັ້ນໂຄ້ງຊິກມອຍຈະເຂົ້າຫາເມື່ອຄ່າຂອງສາກເຂົ້າຫາສູນ – ໂດຍປົກກະຕິຄວນປະໄວ້ຄືເກົ່າ. ເຈົ້າ ສາມາດ ໃຊ້ຄ່ານີ້ເພື່ອໃຫ້ພາບເບິ່ງຊີດໆແບບອານາລັອກ, ແຕ່ແນະນຳໃຫ້ໃຊ້ຕົວເລື່ອນ “global offset” ໃນ color balance rgb ເພື່ອໃຫ້ໄດ້ເອັບເຟັກທີ່ຄ້າຍກັນແທນ.
ເປົ້າໝາຍສີຂາວ
ຂີດຈຳກັດສູງສຸດທີ່ເສັ້ນໂຄ້ງຊິກມອຍຈະເຂົ້າຫາເມື່ອຄ່າຂອງສາກເຂົ້າຫາອະສົງໄຂ – ໂດຍປົກກະຕິຄວນປະໄວ້ຄືເກົ່າ. ເຈົ້າສາມາດໃຊ້ຄ່ານີ້ເພື່ອຕັດຍອດສີຂາວ (clip) ຕາມຄວາມເຂັ້ມຂອງສາກທີ່ກຳນົດໄວ້.

🔗ສີຫຼັກ (primaries)

ຂະຫຍາຍສ່ວນນີ້ເພື່ອຕັ້ງຄ່າສີພື້ນຖານ (primaries) ເອງ. ແນະນຳໃຫ້ໃຊ້ຄ່າ “smooth” ເປັນຈຸດເລີ່ມຕົ້ນ ແລ້ວປັບແຕ່ງໂດຍໃຊ້ຕົວຄວບຄຸມດັ່ງນີ້:

ໝາຍເຫດ: ການຕັ້ງຄ່າເຫຼົ່ານີ້ຈະໃຊ້ໄດ້ສະເພາະກັບໂໝດການປະມວນຜົນ per channel ເທົ່ານັ້ນ.

ສີພື້ນຖານຫຼັກ
ເລືອກຊຸດສີພື້ນຖານທີ່ຈະໃຊ້ເປັນຫຼັກໃນການປັບແຕ່ງ. ນີ້ຄືການປ່ຽນແທນໂປຣໄຟລ໌ເຮັດວຽກໃນສ່ວນນັ້ນ, ເຊິ່ງຈຳເປັນເພື່ອໃຫ້ສາມາດສ້າງຄ່າທີ່ຕັ້ງໄວ້ກ່ອນ (presets) ທີ່ບໍ່ປ່ຽນແປງ ເຖິງແມ່ນວ່າຜູ້ໃຊ້ຈະປ່ຽນໂປຣໄຟລ໌ເຮັດວຽກໃນ pixel pipeline ກໍຕາມ.
ການຫຼຸດຜ່ອນສັນຍານສີ ແດງ/ຂຽວ/ຟ້າ
ຫຼຸດຜ່ອນ (ຫຼຸດລົງ) ຄວາມບໍລິສຸດ ຂອງແມ່ສີແດງ, ຂຽວ ຫຼື ຟ້າ ກ່ອນທີ່ສັນຍານຈະຖືກປະມວນຜົນຜ່ານເສັ້ນໂຄ້ງແຍກແຕ່ລະຊ່ອງສັນຍານຂອງ ຊິກມອຍດ໌. ຜົນທີ່ຕາມມາທີ່ສຳຄັນແມ່ນ ຕອນນີ້ແມ່ນແຕ່ຂໍ້ມູນຂາເຂົ້າທີ່ສະຫວ່າງທີ່ສຸດ ແລະ ມີຄວາມບໍລິສຸດທີ່ສຸດ ກໍຈະຖືກຫຼຸດລົງຢ່າງກົມກືນໄປເປັນແບບໄຮ້ສີໃນສ່ວນທີ່ສະຫວ່າງທີ່ສຸດ. ສິ່ງນີ້ຊ່ວຍຫຼີກລ່ຽງການເກີດຂັ້ນສີ ແລະ ພື້ນທີ່ສີທີ່ເບິ່ງແປຮາບ, ເຊິ່ງມັກຈະພົບເຫັນໄດ້ກັບ, ຕົວຢ່າງ, ໄຟ LED ສີຟ້າ.
ການໝຸນສີ ແດງ/ຂຽວ/ຟ້າ
ໝຸນສີພື້ນຖານໃນສ່ວນທີ່ເສັ້ນໂຄ້ງ per-channel ຖືກນຳໃຊ້. ນີ້ສົ່ງຜົນຕໍ່ທິດທາງໂທນສີເມື່ອເຂົ້າຫາສີຂາວໃນສ່ວນທີ່ສະຫວ່າງສູງສຸດ. ໂດຍປົກກະຕິ ຕົວຄວບຄຸມເຫຼົ່ານີ້ບໍ່ຈຳເປັນຕ້ອງປັບແຕ່ງຫຼາຍຈາກຄ່າເລີ່ມຕົ້ນໃນ “smooth” preset.
ກູ້ຄືນຄວາມບໍລິສຸດ (recover purity)
ກູ້ຄືນຄວາມບໍລິສຸດດັ້ງເດີມບາງສ່ວນ. ຄ່າ 100 ຈະເຮັດໃຫ້ການຫຼຸດທອນທັງໝົດຖືກກູ້ຄືນມາຫຼັງຈາກຂະບວນການແຍກຊ່ອງສີສຳເລັດ. ສິ່ງນີ້ຈະເຮັດໃຫ້ຄ່າໃນຊ່ວງກາງໃກ້ຄຽງກັບຄວາມບໍລິສຸດດັ້ງເດີມ. ຄ່າ 0 ຈະບໍ່ກູ້ຄືນຄວາມບໍລິສຸດເລີຍ, ດັ່ງນັ້ນຍິ່ງທ່ານໃຊ້ການຫຼຸດທອນຫຼາຍເທົ່າໃດ, ຄວາມບໍລິສຸດໃນຮູບສຸດທ້າຍກໍຈະຍິ່ງໜ້ອຍລົງເທົ່ານັ້ນ. ການໝຸນ (rotations) ຈະຖືກກູ້ຄືນສະເໝີ ໂດຍບໍ່ສົນວ່າຄ່າຂອງແຖບເລື່ອນນີ້ຈະເປັນເທົ່າໃດ. ເມື່ອແຖບເລື່ອນນີ້ຢູ່ທີ່ 0, ຜົນໄດ້ຮັບຂອງໂມດູນຈະຖືກຮັບປະກັນວ່າຈະຍັງຄົງຢູ່ໃນຂອບເຂດ gamut ຂອງສີຫຼັກ (base primaries) ທີ່ເລືອກໄວ້.

ໃຫ້ຈື່ໄວ້ວ່າ ມັນບໍ່ຄືກັບໂມດູນ rgb primaries, ນີ້ບໍ່ແມ່ນເຄື່ອງມືສຳລັບການແຕ່ງສີ (color grading) ແບບສ້າງສັນ ແຕ່ເປັນຊຸດຄວບຄຸມເພື່ອໃຫ້ໄດ້ຈຸດເລີ່ມຕົ້ນທີ່ເໝາະສົມສຳລັບການປັບແຕ່ງຕໍ່ໄປ. ເອັບເຟັກຂອງການປັບແຕ່ງເຫຼົ່ານີ້ບໍ່ຄືກັບໂມດູນ rgb primaries ເຖິງແມ່ນວ່າໜ້າຕາຈະເບິ່ງຄ້າຍຄືກັນກໍຕາມ.
