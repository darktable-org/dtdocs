ກະລຸນາຮັບຊາບວ່າໂມດູນນີ້ໄດ້ ຍົກເລີກການນຳໃຊ້ ຕັ້ງແຕ່ darktable 3.6 ແລະ ບໍ່ຄວນໃຊ້ອີກ. ກະລຸນາໃຊ້ ແຜງເຂົ້າເຖິງດ່ວນ ແທນ.

ໂມດູນອຳນວຍຄວາມສະດວກທີ່ລວມເອົາການຄວບຄຸມຈາກ exposure, highlight reconstruction, color balance ແລະ vibrance ເຂົ້າໄວ້ໃນໂມດູນດຽວ.

ເຖິງວ່າໂມດູນນີ້ຈະເປັນວິທີທີ່ສະດວກ ແລະ ວ່ອງໄວໃນການປັບແຕ່ງຮູບພາບແບບງ່າຍດາຍ, ແຕ່ກໍຕ້ອງໄດ້ນຳໃຊ້ດ້ວຍຄວາມລະມັດລະວັງ. ໂດຍປົກກະຕິແລ້ວ ການປັບຄ່າການຮັບແສງຄວນຈະມາກ່ອນ ໂປຣໄຟລ໌ສີນຳເຂົ້າ ໃນ pixelpipe, ແລະ ການປັບແຕ່ງສີຄວນຈະຕາມມາທີຫຼັງ. ເນື່ອງຈາກໂມດູນ ການປັບແຕ່ງພື້ນຖານ ໄດ້ລວມເອົາໜ້າທີ່ທັງໝົດເຫຼົ່ານີ້ເຂົ້າໃນການເຮັດວຽກຂັ້ນຕອນດຽວໃນ pixelpipe, ມັນອາດຈະເຮັດວຽກບໍ່ເຂົ້າກັນໄດ້ດີກັບໂມດູນອື່ນໆ. ດັ່ງນັ້ນ, ຖ້າທ່ານມີແຜນທີ່ຈະໃຊ້ ການປັບແຕ່ງພື້ນຖານ ຮ່ວມກັບໂມດູນອື່ນໆ, ກະລຸນາພິຈາລະນາໃຊ້ໂມດູນ ການຮັບແສງ + ເສັ້ນໂຄ້ງພື້ນຖານ / ເສັ້ນໂຄ້ງໂທນ / ຟິມມິກ rgb + ຄວາມສົມດຸນຂອງສີ ແທນ ເພື່ອໃຫ້ຂັ້ນຕອນເຫຼົ່ານີ້ເກີດຂຶ້ນໃນຕຳແໜ່ງທີ່ຖືກຕ້ອງໃນ pixelpipe.

🔗ສ່ວນຄວບຄຸມໂມດູນ

black level correction
ທຽບເທົ່າກັບການປັບແກ້ລະດັບສີດຳໃນໂມດູນ ການປັບແສງ, ຕົວເລື່ອນນີ້ກຳນົດເກນທີ່ຄ່າສີເທົາເຂັ້ມຈະຖືກຕັດໃຫ້ກາຍເປັນສີດຳສະນິດ. ການຫຼຸດຄ່ານີ້ສາມາດດຶງບາງສີທີ່ເຂັ້ມກັບຄືນມາຢູ່ໃນຂອບເຂດສີໄດ້. ການເພີ່ມຄ່າຕົວເລື່ອນນີ້ອາດຈະເຮັດໃຫ້ຄວາມຕ່າງ ແລະ ຄວາມໂດດເດັ່ນຂອງຮູບພາບເພີ່ມຂຶ້ນ, ແຕ່ມັນສາມາດດັນໃຫ້ສີເຂັ້ມຫຼຸດອອກນອກຂອບເຂດສີໄດ້, ແລະ ຂໍ້ມູນທີ່ຖືກຕັດຈະບໍ່ສາມາດກູ້ຄືນມາໄດ້ໃນຂັ້ນຕອນການປະມວນຜົນພິກເຊວຕໍ່ໄປ. ເພື່ອຄວບຄຸມຄວາມຕ່າງໃນສ່ວນເງົາ, ແມ່ນໃຫ້ໃຊ້ໂມດູນອື່ນໆດີກວ່າ ເຊັ່ນ: ເສັ້ນໂຄ້ງໂທນ ຫຼື ລະດັບ, ເຊິ່ງຈະຊ່ວຍຫຼຸດຜ່ອນຜົນກະທົບທາງລົບເຫຼົ່ານີ້ໃນຂັ້ນຕອນການປະມວນຜົນພິກເຊວຕໍ່ໄປ.
ການຮັບແສງ (exposure)
ປັບການຊົດເຊີຍການຮັບແສງ.

ການປັບຄ່າບວກຈະເຮັດໃຫ້ພາບສະຫວ່າງຂຶ້ນ ແຕ່ອາດເຮັດໃຫ້ນອຍສ໌ (noise) ເພີ່ມຂຶ້ນ.

ການຊົດເຊີຍແສງຄ່າລົບຈະເຮັດໃຫ້ຮູບພາບມືດລົງ. ດ້ວຍລັກສະນະຂອງຮູບພາບດີຈີຕອນ, ສິ່ງນີ້ບໍ່ສາມາດແກ້ໄຂສ່ວນໄຮໄລ້ (highlights) ທີ່ຂາວໂພນທັງໝົດໄດ້, ແຕ່ຈະຊ່ວຍໃຫ້ທ່ານສາມາດກູ້ຄືນຂໍ້ມູນໄດ້ ຖ້າຫາກມີພຽງບາງຊ່ອງສີ RGB ທີ່ຖືກຕັດ (clipped) ເທົ່ານັ້ນ (ເບິ່ງໂມດູນ ການກູ້ຄືນໄຮໄລ້ ສຳລັບຂໍ້ມູນກ່ຽວກັບວິທີການຈັດການກັບພິກເຊລທີ່ຖືກຕັດ).

ການບີບອັດສ່ວນສະຫວ່າງ (highlight compression)
ບີບອັດສ່ວນທີ່ສະຫວ່າງເກີນໄປເພື່ອໃຫ້ເຫັນລາຍລະອຽດຄືນມາ.
contrast
ທຽບເທົ່າກັບແຖບເລື່ອນ contrast ໃນໂມດູນ color balance, ສ່ວນນີ້ແມ່ນໃຊ້ເພື່ອເພີ່ມການແຍກຄ່າຄວາມສະຫວ່າງອ້ອມຮອບຈຸດອ້າງອີງ, ເຊິ່ງສົ່ງຜົນໃຫ້ເສັ້ນໂຄ້ງໂທນສີມີຄວາມຊັນຂຶ້ນ. ແຖບເລື່ອນ middle gray ຈະກຳນົດຈຸດອ້າງອີງສຳລັບຄອນທຣາສ, ແລະ ພິກເຊວໃດທີ່ມີຄວາມສະຫວ່າງກົງກັບຈຸດສີເທົາກາງນີ້ຈະບໍ່ໄດ້ຮັບຜົນກະທົບ. ພິກເຊວທີ່ສະຫວ່າງກວ່າຈຸດສີເທົາກາງຈະສະຫວ່າງຂຶ້ນຕື່ມ, ແລະ ພິກເຊວທີ່ມືດກວ່າຈຸດສີເທົາກາງຈະມືດລົງຕື່ມ.
preserve colors
ຖ້າຫາກມີການນຳໃຊ້ເສັ້ນໂຄ້ງໂທນແບບບໍ່ເປັນເສັ້ນຊື່ກັບແຕ່ລະຊ່ອງສັນຍານ RGB ແຍກກັນ, ປະລິມານການປັບແຕ່ງໂທນທີ່ນຳໃຊ້ກັບແຕ່ລະຊ່ອງສັນຍານສີອາດຈະແຕກຕ່າງກັນ, ແລະ ນີ້ສາມາດເຮັດໃຫ້ເກີດການປ່ຽນແປງຂອງເນື້ອສີ. ດັ່ງນັ້ນ, ເມນູ ຮັກສາສີ ຈຶ່ງມີຫຼາຍວິທີທີ່ແຕກຕ່າງກັນໃນການຄິດໄລ່ “ລະດັບຄວາມສະຫວ່າງ” ຂອງພິກເຊວ. ປະລິມານການປັບແຕ່ງໂທນຈະຖືກຄິດໄລ່ໂດຍອີງໃສ່ຄ່າຄວາມສະຫວ່າງນີ້, ແລະ ຈາກນັ້ນການປັບແຕ່ງແບບດຽວກັນນີ້ຈະຖືກນຳໃຊ້ກັບທັງສາມຊ່ອງສັນຍານ RGB. ຕົວປະມານຄ່າຄວາມສະຫວ່າງທີ່ແຕກຕ່າງກັນ ສາມາດສົ່ງຜົນກະທົບຕໍ່ຄວາມຕ່າງລະດັບສີໃນສ່ວນຕ່າງໆຂອງຮູບພາບ, ເຊິ່ງຂຶ້ນກັບຄຸນລັກສະນະສະເພາະຂອງຮູບພາບນັ້ນ. ຜູ້ໃຊ້ຈຶ່ງສາມາດເລືອກຕົວປະມານຄ່າສະເພາະໃດໜຶ່ງທີ່ໃຫ້ຜົນລັບທີ່ດີທີ່ສຸດສຳລັບຮູບພາບນັ້ນໆ.
middle gray
ຕັ້ງຈຸດສູນກາງສຳລັບຕົວເລື່ອນ ຄວາມຕ່າງລະດັບສີ (contrast). ນີ້ທຽບເທົ່າກັບຕົວເລື່ອນ ຈຸດສູນກາງຄວາມຕ່າງ (contrast fulcrum) ໃນໂມດູນ color balance. ຖ້າຕົວເລື່ອນຄວາມຕ່າງລະດັບສີຖືກຕັ້ງເປັນ 0 ຕົວເລື່ອນນີ້ຈະບໍ່ມີຜົນຫຍັງ.
brightness
ທຽບເທົ່າກັບການເພີ່ມຕົວເລື່ອນ ຄ່າແກມມາ (gamma factor) ໃນໂມດູນ color balance. ການຍ້າຍຕົວເລື່ອນໄປທາງຂວາຈະເພີ່ມຄວາມສະຫວ່າງຂອງຮູບ, ໂດຍເນັ້ນໃສ່ສ່ວນສີປານກາງ (mid-tones).
saturation
ທຽບເທົ່າກັບແຖບເລື່ອນ ຄວາມອີ່ມຕົວຂາອອກ ໃນໂມດູນ ຄວາມສົມດຸນສີ, ແຖບເລື່ອນນີ້ສົ່ງຜົນຕໍ່ຄວາມອີ່ມຕົວ, ຫຼື ຄວາມສົດໃສ ແລະ ຄວາມເຂັ້ມຂອງສີ. ການເລື່ອນແຖບເລື່ອນໄປທາງຂວາຈະເພີ່ມປະລິມານສີໃນຮູບພາບ; ການເລື່ອນແຖບເລື່ອນໄປທາງຊ້າຍຈະຫຼຸດປະລິມານສີໃນຮູບພາບ.
vibrance
ເນັ້ນສີຂອງຮູບພາບໂດຍບໍ່ເຮັດໃຫ້ສີເບິ່ງບໍ່ເປັນທຳມະຊາດ, ເຊິ່ງມັກຈະເກີດຂຶ້ນກັບຕົວເລື່ອນ ຄວາມອີ່ມຕົວ (saturation). ມັນເຮັດວຽກໂດຍການຫລຸດຄວາມສະຫວ່າງຂອງພິກເຊວທີ່ມີຄວາມອີ່ມຕົວຢູ່ແລ້ວ ເພື່ອເຮັດໃຫ້ສີເບິ່ງມີຊີວິດຊີວາຂຶ້ນ. ທ່ານຍັງສາມາດສ້າງເອັບເຟັກທີ່ໜ້າສົນໃຈໄດ້ໂດຍການໃຊ້ຮ່ວມກັບຕົວເລື່ອນຄວາມອີ່ມຕົວ ເພື່ອເນັ້ນໃສ່ພື້ນທີ່ທີ່ມີຄວາມອີ່ມຕົວຫຼາຍ ຫຼື ໜ້ອຍຂອງຮູບ.
ອັດຕະໂນມັດ (auto)
ປັບການເປີດຮັບແສງໂດຍອັດຕະໂນມັດ ໂດຍພິຈາລະນາຈາກຮູບພາບທັງໝົດ, ຫຼື ໃຊ້ ເຄື່ອງມືເລືອກ ເພື່ອເລືອກພື້ນທີ່ຮູບສີ່ແຈສາກໃນຮູບ – ການເປີດຮັບແສງຈະຖືກປັບໂດຍອັດຕະໂນມັດຕາມພື້ນທີ່ທີ່ເລືອກ. ສິ່ງນີ້ຊ່ວຍໃຫ້ເຈົ້າສາມາດຈັດລຳດັບຄວາມສຳຄັນວ່າສ່ວນໃດຂອງຮູບຄວນຈະໄດ້ຮັບແສງທີ່ພໍດີ.
ຕັດແສງ (clip)
ກຳນົດຈຳນວນພິກເຊວທີ່ຈະຖືກຕັດໃຫ້ເປັນສີດຳ ຫຼື ສີຂາວໃນລະຫວ່າງການຄຳນວນອັດຕະໂນມັດ.
