ການຮອງຮັບອຸປະກອນ midi

🔗ບົດນຳ

MIDI ແມ່ນໂປຣໂຕຄໍການສື່ສານທີ່ໃຊ້ໂດຍເຄື່ອງດົນຕີເອເລັກໂຕຣນິກ, ອຸປະກອນສະຕູດິໂອສຽງ ແລະ ແມ່ນແຕ່ “ຄີບອດແຕ່ງຮູບ” ເຊັ່ນ Loupedeck. ອຸປະກອນເຫຼົ່ານີ້ມັກຈະມີປຸ່ມກົດ, ປຸ່ມໝຸນ (encoders) ແລະ ປຸ່ມສະໄລ້ (faders). ປຸ່ມໝຸນແບບ “endless” ສາມາດໝຸນໄດ້ໂດຍບໍ່ມີຈຸດສິ້ນສຸດ ເຊິ່ງເໝາະສຳລັບການປັບຄ່າສະໄລເດີໃນ darktable. ບາງລຸ້ນອາດຈະເປັນແບບມໍເຕີ (motorized) ເຊິ່ງຈະປັບຕຳແໜ່ງໃຫ້ກົງກັບຄ່າໃນໜ້າຈໍໂດຍອັດຕະໂນມັດ.

🔗ປຸ່ມໝຸນແບບໄຮ້ຂີດຈຳກັດ; ການເຂົ້າລະຫັດແບບສຳບູນ / ແບບທຽບຖານ

ອຸປະກອນເຫຼົ່ານີ້ສາມາດສົ່ງຂໍ້ມູນໄດ້ຫຼາຍຮູບແບບ. ປຸ່ມໝຸນສາມາດສົ່ງຕຳແໜ່ງ “absolute” ໃນຊ່ວງ 0-127. darktable ຈະສົ່ງຄ່າກັບໄປຫາອຸປະກອນເພື່ອໃຫ້ໄຟ LED ຫຼື ປຸ່ມສະໄລ້ມໍເຕີ ສະແດງຄ່າທີ່ຖືກຕ້ອງ. ຖ້າເປັນປຸ່ມໝຸນແບບໄຮ້ຂີດຈຳກັດ, ມັນຈະສາມາດປັບຄ່າໄດ້ລະອຽດກວ່າ 128 ຂັ້ນໄດ.

ປຸ່ມໝຸນທີ່ບໍ່ມີໄຟວົງແຫວນອາດຈະສົ່ງຂໍ້ມູນແບບທຽບຖານ (relative) ເຊິ່ງສາມາດປັບຄວາມໄວຕາມການໝຸນໄດ້. darktable ຈະພະຍາຍາມກວດສອບຮູບແບບການເຂົ້າລະຫັດໂດຍອັດຕະໂນມັດ ໂດຍການຟັງ 5 ຂໍ້ຄວາມທຳອິດ. ເມື່ອເລີ່ມໃຊ້ງານ, ທ່ານຄວນໝຸນປຸ່ມໄປທາງຊ້າຍຊ້າໆ 5 ຄັ້ງ. ຖ້າສຳເລັດ ຈະມີຂໍ້ຄວາມແຈ້ງເຕືອນ ຮູບແບບການເຂົ້າລະຫັດທີ່ກວດພົບ (ເຊັ່ນ 127 ຫຼື 63).

🔗ການນຳໃຊ້

ຖ້າອຸປະກອນຂອງທ່ານໄດ້ຮັບການກຳນົດຄ່າ ແລະ ເຊື່ອມຕໍ່ສຳເລັດແລ້ວ, ທ່ານຄວນຈະເຫັນຂໍ້ຄວາມເຊັ່ນ “G#–1 (8) ບໍ່ໄດ້ຖືກກຳນົດ” ເມື່ອທ່ານກົດປຸ່ມ (ອັນທຳອິດແມ່ນລະຫັດຕົວໂນດດົນຕີສຳລັບ “ສຽງ”, ອັນທີສອງແມ່ນຕົວເລກແທນຄ່າ) ຫຼື “CC1,up ບໍ່ໄດ້ຖືກກຳນົດ” ເມື່ອມີການປັບຕົວໝຸນ. ຕອນນີ້ທ່ານພ້ອມແລ້ວທີ່ຈະກຳນົດປຸ່ມ ແລະ ຕົວໝຸນໃຫ້ກັບການເຮັດວຽກຕ່າງໆ. ວິທີທີ່ງ່າຍທີ່ສຸດໃນການເຮັດສິ່ງນີ້ສຳລັບຫຼາຍໆອັນໃນຄັ້ງດຽວແມ່ນໃຫ້ກົດປຸ່ມ ການກຳນົດປຸ່ມລັດແບບເຫັນພາບ (ຢູ່ເບື້ອງຊ້າຍຂອງປຸ່ມການຕັ້ງຄ່າ) ເພື່ອເຂົ້າສູ່ໂໝດການກຳນົດປຸ່ມລັດແບບເຫັນພາບ. ໃນໂໝດນີ້, ເມື່ອທ່ານເລື່ອນເມົາສ໌ໄປວາງໄວ້ເທິງປຸ່ມ ຫຼື ແຖບເລື່ອນ, ຫາກທ່ານກົດປຸ່ມ ຫຼື ໝຸນຕົວໝຸນເທິງອຸປະກອນ MIDI, ມັນຈະຖືກກຳນົດເປັນປຸ່ມລັດໃຫ້ກັບວິດເຈັດນັ້ນທັນທີ. ທ່ານສາມາດທົດສອບມັນໄດ້ທັນທີ (ໃນຂະນະທີ່ຍັງຢູ່ໃນໂໝດການກຳນົດ) ໂດຍການຍ້າຍເມົາສ໌ໄປໄວ້ກາງໜ້າຈໍ (ເພື່ອບໍ່ໃຫ້ທ່ານກຳນົດມັນໃຫ້ກັບວິດເຈັດອື່ນໂດຍບໍ່ຕັ້ງໃຈ) ແລ້ວເຮັດການກະທຳນັ້ນຊ້ຳອີກຄັ້ງ. ຄລິກຂວາເພື່ອປິດໂໝດການກຳນົດ.

ທ່ານອາດຈະຕ້ອງການກຳນົດປຸ່ມເພື່ອເຮັດໜ້າທີ່ແທນປຸ່ມ Ctrl ແລະ Shift. ສຳລັບການຕັ້ງຄ່ານີ້, ທ່ານຈຳເປັນຕ້ອງໃຊ້ໜ້າຕ່າງທາງລັດແບບເຕັມ (ຄລິກຂວາໃສ່ປຸ່ມທາງລັດ ຫຼື ເປີດ ການຕັ້ງຄ່າ ແລ້ວໄປທີ່ແຖບ ທາງລັດ). ໃນລາຍການດ້ານເທິງ (“action”), ໃຫ້ດັບເບິນຄລິກໃສ່ “global/modifiers”. ຈາກນັ້ນ ກົດປຸ່ມ MIDI ທີ່ທ່ານຕ້ອງການກຳນົດໃຫ້ເປັນ Shift. ດັບເບິນຄລິກໃສ່ “global/modifiers” ອີກຄັ້ງ, ແຕ່ຄັ້ງນີ້ຫຼັງຈາກກຳນົດປຸ່ມແລ້ວ ໃຫ້ປ່ຽນ element ສຳລັບທາງລັດທີ່ສ້າງຂຶ້ນໃໝ່ໃນລາຍການດ້ານລຸ່ມຈາກ “shift” ເປັນ “ctrl”. ຕອນນີ້ທ່ານສາມາດໃຊ້ອຸປະກອນ MIDI ຂອງທ່ານຮ່ວມກັບເມົາສ໌ເພື່ອເຂົ້າເຖິງການເຮັດວຽກສ່ວນໃຫຍ່ໃນ darktable ໄດ້. ຫຼັງຈາກໝາຍຕິກ “enable fallbacks” ໃນໜ້າຕ່າງທາງລັດ, ການກົດ Ctrl ຄ້າງໄວ້ໃນຂະນະທີ່ໝຸນຕົວປັບ (encoder) ຈະເຮັດໃຫ້ມັນຊ້າລົງ 10 ເທົ່າ, ໃນຂະນະທີ່ການກົດ Shift ຄ້າງໄວ້ຈະເຮັດໃຫ້ມັນໄວຂຶ້ນ.

ອຸປະກອນຫຼາຍອັນທີ່ຜະລິດໂດຍ Behringer ມີໄຟ LED ເປັນວົງມົນອ້ອມຮອບປຸ່ມໝຸນ (encoder knobs). ໄຟເຫຼົ່ານີ້ໃຊ້ຮູບແບບທີ່ແຕກຕ່າງກັນຂຶ້ນຢູ່ກັບວ່າພວກມັນຖືກກຳນົດໃຫ້ກັບ slider ຫຼື combobox ໃດ:

  • ຫາກ slider ມີຄ່າແຕ່ -1 ຫາ +1, ຈະມີພຽງໄຟ LED ເຄິ່ງກາງເທົ່ານັ້ນທີ່ຮຸ່ງຢູ່ທີ່ຄ່າສູນ. ເມື່ອປັບໄປທາງລົບ ໄຟທາງເບື້ອງຊ້າຍຈະຄ່ອຍໆຮຸ່ງຂຶ້ນ, ເມື່ອປັບໄປທາງບວກ ໄຟທາງເບື້ອງຂວາຈະຮຸ່ງຂຶ້ນ.
  • ຫາກ slider ມີຄ່າແຕ່ 0-100%, ທ່ານຈະເຫັນໄຟ LED ຮຸ່ງຂຶ້ນຫຼາຍຂຶ້ນເມື່ອໝຸນໄປທາງຂວາ, ຈົນກວ່າຈະຮຸ່ງທັງໝົດທີ່ 100%.
  • ຄ່າຕົວເລກອື່ນໆ ຈະໃຊ້ໄຟ LED 1 ຫຼື 2 ດວງ ເພື່ອສະແດງຄ່າລະຫວ່າງກາງ.
  • ລາຍການເລືອກ (Dropdowns) ຈະໃຊ້ໄຟ LED 1 ດວງ ສໍາລັບຕົວເລືອກທີ່ຢູ່ໃນຮອບທຳອິດຂອງການໝຸນ ແລະ 2 ດວງ ໃນຮອບທີສອງ.

🔗ການແກ້ໄຂບັນຫາ ແລະ ການຕັ້ງຄ່າ

ຫາກທ່ານບໍ່ເຫັນຂໍ້ຄວາມແຈ້ງເຕືອນ “not assigned” ຢູ່ເທິງສຸດຂອງໜ້າຈໍເມື່ອອັດປຸ່ມ ຫຼື ໝຸນປຸ່ມ, ທ່ານຄວນທົດສອບເບິ່ງວ່າແອັບພລິເຄຊັນ MIDI ອື່ນໆ ສາມາດເຫັນອຸປະກອນໄດ້ຫຼືບໍ່. ພາຍໃຕ້ Linux ທ່ານຈຳເປັນຕ້ອງມີ Alsa ຕິດຕັ້ງຢູ່. ຫຼັງຈາກສຽບອຸປະກອນເຂົ້າແລ້ວ, dmesg ຄວນຈະສະແດງຂໍ້ຄວາມຄືແນວນີ້:

usb 1-1: new full-speed USB device number 2 using xhci_hcd
...
mc: Linux media interface: v0.10
usbcore: registered new interface driver snd-usb-audio

Darktable ໃຊ້ PortMidi ເຊິ່ງເປັນເລເຢີຂ້າມແພລັດຟອມແບບງ່າຍດາຍ ເພື່ອເຂົ້າເຖິງ API ຂອງລະບົບປະຕິບັດການ (Alsa, Core Midi, WinMM). ຖ້າທ່ານກຳລັງຄອມໄພລ໌ດ້ວຍຕົນເອງ, ໃຫ້ແນ່ໃຈວ່າທ່ານໄດ້ລວມເອົາໄລບຣາຣີນີ້ແລ້ວ.

ການເປີດ darktable ດ້ວຍ -d input ຈະສະແດງຂໍ້ມູນເພີ່ມເຕີມ. ມັນຈະພະຍາຍາມເປີດອຸປະກອນ MIDI ໄດ້ສູງສຸດ 10 ອຸປະກອນ ຕາມລຳດັບທີ່ກວດພົບ.

ບັນຫາທີ່ອາດເກີດຂຶ້ນມີ 2 ຢ່າງ:

  • ອຸປະກອນທີ່ເຈົ້າບໍ່ຕ້ອງການໃຊ້ອາດຖືກເປີດຂຶ້ນມາຄືເກົ່າ (ແລະ ອາດກໍ່ໃຫ້ເກີດພຶດຕິກຳທີ່ບໍ່ເໝາະສົມ, ເຊັ່ນການເລີ່ມສະແດງດອກໄມ້ໄຟກ່ອນເວລາ – ເບິ່ງ ເອກະສານນີ້); ຫຼື

  • ອຸປະກອນອາດຈະປະກົດຂຶ້ນຕາມລໍາດັບທີ່ແຕກຕ່າງກັນໃນການເລີ່ມຕົ້ນລະບົບຄັ້ງຕໍ່ໄປ (ຕົວຢ່າງ: ເພາະວ່າພວກມັນຖືກສຽບໃສ່ພອດ usb ທີ່ແຕກຕ່າງກັນ). ເນື່ອງຈາກການກໍານົດຄ່າຖືກເກັບໄວ້ດ້ວຍໝາຍເລກອຸປະກອນເທົັ້ນ, ການຈັດລໍາດັບໃໝ່ຈະເຮັດໃຫ້ເລືອກຜັງການຈັດວາງທີ່ບໍ່ຖືກຕ້ອງ.

ເຈົ້າສາມາດກຳນົດໄດ້ວ່າຈະໂຫຼດອຸປະກອນໃດໃນຕຳແໜ່ງໃດໜຶ່ງ ແລະ ອັນໃດທີ່ຈະຂ້າມໄປ ໂດຍໃຊ້ພາຣາມິເຕີ ການຕັ້ງຄ່າ > ອື່ນໆ > ອິນເຕີເຟດ > ຈັດລຳດັບ ຫຼື ຍົກເວັ້ນອຸປະກອນ midi. ເພື່ອຂ້າມການໂຫຼດ BCR2000 ໃນຕົວຢ່າງຂ້າງເທິງ ແລະ ກຳນົດອຸປະກອນອີກສອງອັນໃສ່ໃນຊ່ອງໝາຍເລກ 0 ແລະ 2, ເຈົ້າສາມາດຕັ້ງຄ່າພາຣາມິເຕີນີ້ເປັນ “BeatStep,dontuse,X-TOUCH,-BCR2000”. ສິ່ງນີ້ຈະເຮັດໃຫ້ BeatStep ເປັນອຸປະກອນ midi0, ປະ midi1 ໄວ້ໂດຍບໍ່ໄດ້ໃຊ້ ແລະ ຈະບໍ່ໂຫຼດ BCR2000 ເລີຍ, ແຕ່ຖ້າມີອຸປະກອນອື່ນໆເຊື່ອມຕໍ່, ພວກມັນຈະສະແດງເປັນ midi3, midi4 ແລະ ຕໍ່ໆໄປ. ການເພີ່ມ “,-” ຢູ່ທ້າຍຈະເປັນການປ້ອງກັນບໍ່ໃຫ້ໂຫຼດອຸປະກອນເພີ່ມເຕີມອີກ.

ຖ້າທ່ານຕັ້ງເປັນເຄື່ອງໝາຍລົບ “-” ພຽງຢ່າງດຽວ, ມັນຈະບໍ່ໂຫລດອຸປະກອນໃດໆເລີຍ.

ສໍາລັບອຸປະກອນທີ່ໃຊ້ການເຂົ້າລະຫັດແບບສຳພັດ (relative encoding) ດັ່ງທີ່ກ່າວມາຂ້າງເທິງ, ທ່ານຈະຕ້ອງເຮັດຂັ້ນຕອນການໝຸນຊ້າຍຊ້າໆ ໃນທຸກໆຄັ້ງທີ່ເລີ່ມຕົ້ນໃໝ່, ຫຼື ເພີ່ມການເຂົ້າລະຫັດທີ່ພົບລົງໃນຂໍ້ຄວາມການຕັ້ງຄ່າ. ຕົວຢ່າງ “Loupedeck:127”.

ເຄື່ອງຄວບຄຸມ MIDI ບາງອັນມີປຸ່ມທີ່ມີໄຟຢູ່ທາງລຸ່ມ. ສິ່ງເຫຼົ່ານີ້ສາມາດໃຊ້ເພື່ອສະຫຼັບການຕັ້ງຄ່າ ແລະ ສະແດງສະຖານະປະຈຸບັນໂດຍການເປີດ ຫຼື ປິດໄຟ. ເພື່ອໃຫ້ສິ່ງນີ້ເຮັດວຽກໄດ້, darktable ຈະກວດສອບເປັນໄລຍະ (ສອງສາມຄັ້ງຕໍ່ວິນາທີ) ວ່າ, ຕົວຢ່າງ, ຕຳແໜ່ງຂອງປຸ່ມສະຫຼັບໃນໜ້າຈໍມີການປ່ຽນແປງຫຼືບໍ່, ແລະ ສົ່ງຂໍ້ຄວາມໄປຫາປຸ່ມຂອງອຸປະກອນ MIDI ທີ່ເຊື່ອມຕໍ່ໄວ້ເພື່ອເປີດ ຫຼື ປິດໄຟຂອງພວກມັນ. ແຕ່ຖ້າມີອຸປະກອນທີ່ບໍ່ຮູ້ຈັກຖືກເຊື່ອມຕໍ່ໂດຍບໍ່ຕັ້ງໃຈ, ສິ່ງນີ້ອາດຈະເປັນສິ່ງທີ່ບໍ່ເພິ່ງປະສົງ. ດັ່ງນັ້ນ ໂດຍຄ່າເລີ່ມຕົ້ນ darktable ຈະລໍຖ້າຈົນກວ່າຈະໄດ້ຮັບຂໍ້ຄວາມ “note” ຈາກ ປຸ່ມ MIDI ກ່ອນທີ່ຈະສົ່ງຂໍ້ຄວາມ ເປີດ/ປິດ ໄຟ “note” ກັບຄືນ ໄປຫາປຸ່ມນັ້ນ (ແລະ ປຸ່ມທີ່ມີໝາຍເລກຕ່ຳກວ່າ). ດ້ວຍວິທີນີ້ ຈະບໍ່ມີການກຳນົດປຸ່ມເກີນກວ່າທີ່ມີຢູ່ໃນອຸປະກອນ. ຖ້າທ່ານຕ້ອງການໃຊ້ໄຟຂອງທຸກປຸ່ມໃນທັນທີ (ແທນທີ່ຈະຕ້ອງກົດປຸ່ມທີ່ສູງທີ່ສຸດໜຶ່ງຄັ້ງໃນແຕ່ລະຄັ້ງທີ່ໃຊ້ງານ) ທ່ານສາມາດລະບຸຈຳນວນປຸ່ມໃນສ່ວນການຕັ້ງຄ່າ “order or exclude MIDI devices”, ຕົວຢ່າງ: “BeatStep:63:16”.

🔗ອຸປະກອນທີ່ຢືນຢັນແລ້ວວ່າໃຊ້ງານໄດ້

ລະບົບການກຳນົດປຸ່ມລັດໄດ້ຮັບການທົດສອບຢ່າງລະອຽດກັບອຸປະກອນ Behringer ແລະ ມີລະຫັດສະເພາະເພື່ອຈັດການກັບຟີເຈີພິເສດຂອງພວກມັນ. ອຸປະກອນອື່ນໆທັງໝົດຈະຖືກປະຕິບັດຄືກັບ “generic midi” ແລະ ອາດຈະໃຊ້ງານໄດ້ (ຫຼື ບໍ່ໄດ້) ດີ. ຖ້າເຈົ້າສາມາດຕັ້ງຄ່າອຸປະກອນ MIDI ໃຫ້ໃຊ້ງານໄດ້ໂດຍທີ່ບໍ່ໄດ້ລະບຸໄວ້ທາງລຸ່ມນີ້, ຈະເປັນການດີຫຼາຍຖ້າເຈົ້າຊ່ວຍໃຫ້ຂໍ້ມູນ ເພື່ອເປັນປະໂຫຍດໃຫ້ກັບຄົນອື່ນ ຫາກມີຂັ້ນຕອນພິເສດທີ່ຈຳເປັນ. ເຈົ້າສາມາດເຮັດສິ່ງນີ້ໄດ້ໂດຍການສົ່ງ pull request ເພື່ອແກ້ໄຂໜ້ານີ້ ຫຼື ໂດຍການ ແຈ້ງບັນຫາ ທີ່ມີຂໍ້ມູນທີ່ຈຳເປັນ.

🔗Behringer X-touch Mini / Compact

ອຸປະກອນເຫຼົ່ານີ້ຄວນຢູ່ໃນ Standard Mode (ບໍ່ແມ່ນ MC). ເລເຢີ A ແລະ B ໄດ້ຮັບການຮອງຮັບໃນລະດັບໜຶ່ງ, ແນວໃດກໍຕາມ, ເນື່ອງຈາກອຸປະກອນບໍ່ໄດ້ສົ່ງການແຈ້ງເຕືອນເມື່ອມີການສະຫຼັບເລເຢີ, ແລະ ເນື່ອງຈາກໄຟ (ທັງພາຍໃຕ້ປຸ່ມ ແລະ ຮູບແບບອ້ອມປຸ່ມໝຸນ) ຖືກຕັ້ງຄ່າຕາມເລເຢີທີ່ darktable ເຂົ້າໃຈວ່າມີການເຄື່ອນໄຫວຢູ່, ທຸກຢ່າງຈະຖືກອັບເດດໃຫ້ຄົບຖ້ວນຫຼັງຈາກທີ່ເຈົ້າກົດ ຫຼື ໝຸນ ບາງຢ່າງໃນເລເຢີ “ໃໝ່” ເທົ່ານັ້ນ. ຄາດວ່າຈະໃຊ້ຄ່າເລີ່ມຕົ້ນ; ຖ້າຫາກມີການປ່ຽນແປງໃດໆ ສາມາດກູ້ຄືນໄດ້ໂດຍໃຊ້ X-Touch Editor

🔗Behringer BCR2000 / BCF2000

ອຸປະກອນເຫຼົ່ານີ້ສາມາດປັບແຕ່ງໄດ້ສູງ ດັ່ງນັ້ນຈຶ່ງມີການຕັ້ງຄ່າຫຼາຍຢ່າງທີ່ອາດເຮັດໃຫ້ການເຮັດວຽກກັບໂມດູນ MIDI ຂອງ darktable ຊັບຊ້ອນຂຶ້ນ. ສາມາດໃຊ້ ເຄື່ອງມື BC Manager (ມີໃຫ້ສຳລັບ Windows ແລະ MacOS) ເພື່ອຕັ້ງຄ່າພວກມັນ. ວິທີທີ່ງ່າຍທີ່ສຸດແມ່ນການຣີເຊັດຕົວເຂົ້າລະຫັດ (encoders) ແລະ ປຸ່ມທັງໝົດໃຫ້ເປັນຄ່າທີ່ງ່າຍທີ່ສຸດ, ເຊິ່ງສາມາດເຮັດໄດ້ (ສຳລັບ BCR2000) ໂດຍໃຊ້ ໄຟລ໌ນີ້. ເຈົ້າສາມາດສົ່ງມັນໄປຍັງເຄື່ອງດ້ວຍ BC Manager ຫຼື (ໃນ Linux) ດ້ວຍ amidi. ນອກຈາກນີ້ຍັງມີການຕັ້ງຄ່າທົ່ວໂລກທີ່ເອີ້ນວ່າ “Deadtime” ເຊິ່ງກຳນົດວ່າ BCR ຈະເມີີນເສີີຍຕໍ່ຂໍ້ຄວາມທີ່ສົ່ງເຂົ້າມາ ດົນປານໃດຫຼັງຈາກສົ່ງການອັບເດດອອກໄປ. ສິ່ງນີ້ແມ່ນເພື່ອຫຼີກລ່ຽງການເກີດ feedback loops, ແຕ່ສຳລັບ darktable ມັນໝາຍເຖິງການບລັອກການປັບຄ່າທີ່ສົ່ງກັບຄືນມາທັນທີຫຼັງຈາກການໝຸນແຕ່ລະຄັ້ງ. ດັ່ງນັ້ນ Deadtime ຈຶ່ງຕ້ອງຖືກຕັ້ງເປັນ 0.

🔗Arturia Beatstep

ປຸ່ມໝຸນແຕ່ລະອັນສາມາດຖືກຕັ້ງຄ່າໃຫ້ສົ່ງຄ່າແບບສຳບູນ (0-127) ຫຼື ການປ່ຽນແປງ (+/- 1, 2, 3, … ໃນການເຂົ້າລະຫັດທີ່ຕ່າງກັນ). ຄ່າທີ່ແນະນຳແມ່ນ Relative #1 ສຳລັບປຸ່ມທັງໝົດ ໂດຍຕັ້ງ Knob Acceleration ເປັນ Slow (Off) ຫຼື Medium. ຈາກນັ້ນໃຫ້ໃສ່ຂໍ້ຄວາມ BeatStep:63:16 ໃນ ການຕັ້ງຄ່າ > ອື່ນໆ > ອິນເຕີເຟດ > ຈັດລຳດັບ ຫຼື ຍົກເວັ້ນອຸປະກອນ midi. ສິ່ງນີ້ສາມາດຕັ້ງຄ່າໄດ້ດ້ວຍ Midi Control Center, ເຊິ່ງມີໃຫ້ສຳລັບ Windows ຫຼື MacOS.
