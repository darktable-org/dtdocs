AI

ຄວບຄຸມຄຸນສົມບັດ AI ຂອງ darktable: ເປີດ ຫຼື ປິດໃຊ້ງານ, ເລືອກຕົວເລັ່ງຮາດແວສຳລັບການປະມວນຜົນໂມເດວ (model inference), ຊີ້ darktable ໄປຫາໄລບຣາຣີ ONNX Runtime, ແລະ ຈັດການໂມເດວ AI ທີ່ມີຢູ່ໃນດິສກ໌.

ຄຸນສົມບັດ AI ຖືກຂັບເຄື່ອນໂດຍ ONNX Runtime. ສິ່ງທີ່ເຮັດວຽກໄດ້ທັນທີ ແລະ ການເລັ່ງ GPU ທີ່ສາມາດເພີ່ມເຂົ້າໃນແຕ່ລະແພລັດຟອມມີດັ່ງນີ້:

ລະບົບປະຕິບັດການ ທີ່ມາພ້ອມກັບແອັບ ການເລັ່ງຄວາມໄວ GPU ທາງເລືອກ
Linux CPU ເທົ່ານັ້ນ NVIDIA CUDA, AMD ROCm/MIGraphX, Intel OpenVINO
Windows DirectML (GPU DirectX 12 ໃດກໍໄດ້) NVIDIA CUDA, Intel OpenVINO
macOS CoreML (Apple Silicon, GPU ໃນຕົວ) –

ສະຄຣິບຕິດຕັ້ງສຳລັບ GPU runtimes ແມ່ນມີຄຳອະທິບາຍຢູ່ລຸ່ມນີ້; ເບິ່ງ ການເລັ່ງ GPU ສຳລັບຄຳແນະນຳທັງໝົດ.

ສຳລັບຄຳອະທິບາຍຢ່າງລະອຽດເພີ່ມເຕີມກ່ຽວກັບວິທີການເຮັດວຽກຂອງຄຸນສົມບັດ AI – ສ່ວນການລັນ (inference runtime), ຜູ້ໃຫ້ບໍລິການການປະມວນຜົນ (execution providers), ໂຄງສ້າງໂມເດວ, ການເລັ່ງຄວາມໄວ GPU, ແລະ ການແກ້ໄຂບັນຫາ – ໃຫ້ເບິ່ງຫົວຂໍ້ພິເສດ ຄຸນສົມບັດ AI.

🔗ທົ່ວໄປ

ເປີດໃຊ້ງານຄຸນສົມບັດ AI
ປຸ່ມຄວບຄຸມຫຼັກສຳລັບຄຸນສົມບັດ AI ທັງໝົດ. ເມື່ອປິດໃຊ້ງານ, ຈະບໍ່ມີການໂຫຼດ ONNX Runtime, ບໍ່ມີການສະແກນໄດເຣັກທໍຣີໂມເດວ, ແລະ ໂມດູນທີ່ຂຶ້ນກັບ AI ຈະຖືກເຊື່ອງໄວ້. ປິດສິ່ງນີ້ເພື່ອຫຼຸດຜ່ອນການໃຊ້ໜ່ວຍຄວາມຈຳ ແລະ ຄ່າໃຊ້ຈ່າຍໃນການເລີ່ມຕົ້ນທີ່ກ່ຽວຂ້ອງກັບ AI ເມື່ອເຈົ້າບໍ່ຈຳເປັນຕ້ອງໃຊ້ (ຄ່າເລີ່ມຕົ້ນແມ່ນປິດ).
ການເລັ່ງ AI
ຕົວເລັ່ງຮາດແວທີ່ໃຊ້ສຳລັບການປະມວນຜົນໂມເດວ (model inference). ລາຍການຈະສະແດງສະເພາະຜູ້ໃຫ້ບໍລິການທີ່ມີຢູ່ໃນປັດຈຸບັນຕາມທີ່ຮອງຮັບໂດຍ ONNX Runtime ທີ່ໂຫຼດມາ. ການຕິດຕັ້ງ ONNX Runtime ອື່ນຈະເຮັດໃຫ້ລາຍການນີ້ອັບເດດ.
  • auto ເລືອກຜູ້ໃຫ້ບໍລິການທີ່ດີທີ່ສຸດທີ່ມີຢູ່ສຳລັບໄລບຣາຣີທີ່ໂຫຼດມາ, ໂດຍຈະກັບໄປໃຊ້ CPU ຖ້າບໍ່ມີຕົວເລັ່ງໃດເລີ່ມເຮັດວຽກ.
  • CPU ປະມວນຜົນໃນຊີພີຢູ. ສາມາດໃຊ້ໄດ້ສະເໝີ.
  • NVIDIA CUDA ໃຊ້ NVIDIA GPUs ຜ່ານ cuDNN (Linux, Windows; ຕ້ອງການການຕິດຕັ້ງ ONNX Runtime ທີ່ຮອງຮັບ CUDA).
  • AMD MIGraphX ໃຊ້ AMD GPUs ຜ່ານ ROCm (Linux ເທົ່ານັ້ນ; ຕ້ອງການການຕິດຕັ້ງ ONNX Runtime ທີ່ຮອງຮັບ MIGraphX).
  • Intel OpenVINO ໃຊ້ Intel GPUs ແລະ iGPUs ຜ່ານ OpenVINO (Linux, Windows; ຕ້ອງການການຕິດຕັ້ງ ONNX Runtime ທີ່ຮອງຮັບ OpenVINO).
  • Windows DirectML ໃຊ້ GPU ທີ່ຮອງຮັບ DirectX 12 ໃດໜຶ່ງ (Windows; ແຖມມາໃຫ້ໂດຍມາດຕະຖານ).
  • Apple CoreML ໃຊ້ Apple Neural Engine ແລະ GPU ໃນຕົວ (macOS; ແຖມມາໃຫ້ໂດຍມາດຕະຖານ).

ຄລິກສອງຄັ້ງທີ່ປ້າຍຊື່ເພື່ອຕັ້ງຄ່າກັບເປັນຄ່າເລີ່ມຕົ້ນ. ຖ້າຜູ້ໃຫ້ບໍລິການທີ່ເລືອກບໍ່ສາມາດເລີ່ມເຮັດວຽກກັບ ONNX Runtime ທີ່ໂຫຼດຢູ່ໃນປັດຈຸບັນ (ຕົວຢ່າງ: ຖ້າໄລບຣາຣີຖືກສ້າງຂຶ້ນໂດຍບໍ່ມີຜູ້ໃຫ້ບໍລິການນັ້ນ) ຂໍ້ຄວາມ ບໍ່ສາມາດໃຊ້ໄດ້, ຈະກັບໄປໃຊ້ CPU ຈະປາກົດຂຶ້ນຖັດຈາກກ່ອງເລືອກ. ຫຼັງຈາກປ່ຽນໄລບຣາຣີ ONNX Runtime, ຂໍ້ຄວາມຈະປ່ຽນເປັນ ເລີ່ມຕົ້ນໃໝ່ເພື່ອປັບໃຊ້ ຈົນກວ່າ darktable ຈະຖືກເລີ່ມຕົ້ນໃໝ່.

ໄລບຣາຣີ ONNX Runtime
ເສັ້ນທາງໄປຫາໄລບຣາຣີທີ່ໃຊ້ຮ່ວມກັນ (libonnxruntime.so* ໃນ Linux, onnxruntime.dll ໃນ Windows) ທີ່ darktable ຄວນໂຫຼດແທນອັນທີ່ແຖມມາໃຫ້. ປ່ອຍຫວ່າງໄວ້ເພື່ອໃຊ້ໄລບຣາຣີທີ່ແຖມມາໃຫ້ (ເບິ່ງຕາຕະລາງຂ້າງເທິງສຳລັບແຕ່ລະ OS). ເພື່ອໃຊ້ GPU runtime, ໃຫ້ຕິດຕັ້ງອັນໜຶ່ງຜ່ານສະຄຣິບທີ່ອະທິບາຍໄວ້ຂ້າງລຸ່ມນີ້ ແລະ ຊີ້ມາທີ່ຊ່ອງນີ້. ຄລິກສອງຄັ້ງທີ່ປ້າຍຊື່ເພື່ອຕັ້ງເປັນຄ່າຫວ່າງ. ການປ່ຽນແປງຈະມີຜົນຫຼັງຈາກເລີ່ມຕົ້ນ darktable ໃໝ່. ເຊື່ອງໄວ້ໃນ macOS, ເຊິ່ງ ONNX Runtime ຖືກເຊື່ອມໂຍງແບບສະແຕຕິກກັບການຮອງຮັບ CoreML.

ທາງດ້ານຂວາຂອງຊ່ອງເສັ້ນທາງມີສອງປຸ່ມ:

  • browse (ໄອຄອນໂຟນເດີ) – ເປີດຕົວເລືອກໄຟລ໌ເພື່ອເລືອກໄລບຣາຣີ (library) ONNX Runtime ທີ່ກຳນົດເອງ. ການເລືອກຈະຖືກກວດສອບໂດຍການໂຫຼດໄລບຣາຣີ ແລະ ກວດສອບເວີຊັນ ແລະ ຜູ້ໃຫ້ບໍລິການການປະມວນຜົນທີ່ມີຢູ່; ຖ້າໄຟລ໌ບໍ່ແມ່ນການສ້າງ ONNX Runtime ທີ່ຖືກຕ້ອງ ມັນຈະຖືກປະຕິເສດ ແລະ ເສັ້ນທາງເດີມຈະຖືກກູ້ຄືນມາ.
  • detect – ສະແກນຕຳແໜ່ງມາດຕະຖານຂອງລະບົບເພື່ອຫາໄລບຣາຣີ ONNX Runtime (ການຕິດຕັ້ງຜ່ານຕົວຈັດການແພັກເກັດ, /usr/lib, /usr/local/lib, ~/.local/lib). ຖ້າພົບຫຼາຍອັນ ທ່ານຈະຖືກຖາມໃຫ້ເລືອກ; ຖ້າພົບອັນດຽວມັນຈະຖືກນຳໃຊ້ໂດຍອັດຕະໂນມັດ. ມີປະໂຫຍດເມື່ອທ່ານໄດ້ຕິດຕັ້ງ ONNX Runtime ຜ່ານຕົວຈັດການແພັກເກັດຂອງລະບົບ ຫຼື ຜ່ານສະຄຣິບຕິດຕັ້ງທີ່ອະທິບາຍໄວ້ຂ້າງລຸ່ມນີ້.

🔗ການຕິດຕັ້ງ GPU ONNX Runtime

ການເລັ່ງຄວາມໄວ GPU ໃນ Linux ແລະ Windows (NVIDIA CUDA, AMD MIGraphX, Intel OpenVINO) ຕ້ອງການການສ້າງ ONNX Runtime ທີ່ຮອງຮັບ GPU, ເຊິ່ງ darktable ບໍ່ໄດ້ໃຫ້ມາໃນຕົວແອັບ. ສະຄຣິບຕິດຕັ້ງຈະຈັດການເລື່ອງນີ້ແບບຄົບວົງຈອນ – ກວດສອບ GPU ຂອງທ່ານ, ດາວໂຫຼດ runtime ທີ່ກົງກັນ, ກວດສອບຄວາມຖືກຕ້ອງ, ແລະ ຕິດຕັ້ງພາຍໃຕ້ບັນຊີຜູ້ໃຊ້ຂອງທ່ານ.

ເບິ່ງ ການເລັ່ງ GPU ສຳລັບຄຳແນະນຳທັງໝົດ: ຕົວຕິດຕັ້ງແບບແຖວດຽວສຳລັບ Linux ແລະ Windows, ເງື່ອນໄຂເບື້ອງຕົ້ນ, ຂໍ້ກຳນົດຂອງ GPU ແລະ ໄດເວີ, ການຕິດຕັ້ງແບບກຳນົດເອງ, ການສ້າງ AMD ONNX Runtime ຈາກຊອດໂຄ້ດ (source), ແລະ ການແກ້ໄຂບັນຫາ.

ຫຼັງຈາກຕິດຕັ້ງແລ້ວ, ໃຫ້ເລີ່ມຕົ້ນ darktable ໃໝ່, ຈາກນັ້ນໃຊ້ປຸ່ມ detect ຂ້າງເທິງເພື່ອຊີ້ darktable ໄປຫາໄລບຣາຣີທີ່ຕິດຕັ້ງໃໝ່ (ຫຼື ເລືອກໄຟລ໌ດ້ວຍຕົນເອງດ້ວຍປຸ່ມ browse).

🔗ໂມເດວ

ເຄິ່ງລຸ່ມຂອງແຖບຈະສະແດງລາຍຊື່ໂມເດວ AI ທີ່ darktable ຮູ້ຈັກ – ທັງອັນທີ່ດາວໂຫຼດມາແລ້ວ ແລະ ອັນທີ່ມີໃຫ້ຈາກຄັງເກັບໂມເດວ darktable-ai.

ລາຍຊື່ໂມເດວ
ແຕ່ລະແຖວມີຄໍລຳດັ່ງນີ້:
  • select (ຊ່ອງໝາຍຊ້າຍສຸດ) – ຮວມໂມເດວເຂົ້າໃນການດຳເນີນການແບບກຸ່ມ (ດາວໂຫຼດອັນທີ່ເລືອກ, ລຶບອັນທີ່ເລືອກ). ບໍ່ຂຶ້ນກັບສະຖານະການເປີດໃຊ້ງານ. ຊ່ອງໝາຍຢູ່ສ່ວນຫົວຈະປ່ຽນທຸກແຖວພ້ອມກັນ.
  • name – ຊື່ໂມເດວ.
  • ປຸ່ມຂໍ້ມູນ (ໄອຄອນ i) – ຄລິກເພື່ອເປີດບັດໂມເດວທີ່ມີຂໍ້ມູນເມຕາຄົບຖ້ວນ: ຂອບເຂດ, ຜູ້ສ້າງ, ແຫຼ່ງທີ່ມາ, ເອກະສານອ້າງອີງ, ໃບອະນຸຍາດ, ຂໍ້ມູນການຝຶກອົບຮົມ, ໃບອະນຸຍາດຂໍ້ມູນ, ໝາຍເຫດ.
  • version – ຂໍ້ຄວາມເວີຊັນຂອງໂມເດວຈາກລາຍການໃນຄັງເກັບຂໍ້ມູນ.
  • task – ໜ້າທີ່ທີ່ໂມເດວນີ້ໃຫ້ບໍລິການ: mask (ໜ້າກາກ), denoise (ຫຼຸດສັນຍານລົບກວນ), rawdenoise (ຫຼຸດສັນຍານລົບກວນ raw), upscale (ຂະຫຍາຍຂະໜາດ).
  • enabled – ໝາຍໂມເດວວ່າເປັນໂມເດວທີ່ໃຊ້ງານຢູ່ສຳລັບໜ້າທີ່ນັ້ນ. ສາມາດມີໂມເດວທີ່ໃຊ້ງານຢູ່ໄດ້ພຽງອັນດຽວຕໍ່ໜ້າທີ່ໃນແຕ່ລະຄັ້ງ: ການໝາຍໃນໂມເດວທີສອງຂອງໜ້າທີ່ດຽວກັນຈະຍົກເລີກການໝາຍໂມເດວທີ່ເຄີຍໃຊ້ງານກ່ອນໜ້ານັ້ນໂດຍອັດຕະໂນມັດ, ຄືກັບປຸ່ມວິທະຍຸ (radio button). ການຍົກເລີກການໝາຍໂມເດວທີ່ໃຊ້ງານຢູ່ຈະເຮັດໃຫ້ໜ້າທີ່ນັ້ນບໍ່ມີໂມເດວທີ່ໃຊ້ງານຈົນກ່ວາຈະເລືອກອັນອື່ນ. ໂມດູນທີ່ຂຶ້ນກັບ AI ຈະໃຊ້ໂມເດວໃດກໍຕາມທີ່ກຳລັງໃຊ້ງານຢູ່ໃນປັດຈຸບັນສຳລັບໜ້າທີ່ຂອງພວກເຂົາ.
  • status – ດາວໂຫຼດແລ້ວ, ຍັງບໍ່ໄດ້ດາວໂຫຼດ, ມີເວີຊັນໃໝ່ໃຫ້ອັບເດດ, ຫຼື ຕ້ອງໄດ້ອັບເດດ.
  • default – yes ຖ້າໂມເດວຢູ່ໃນຊຸດເລີ່ມຕົ້ນທີ່ຜູ້ພັດທະນາແນະນຳ (ເລືອກໂດຍ ດາວໂຫຼດຄ່າເລີ່ມຕົ້ນ), no ຖ້າບໍ່ແມ່ນ.
ດາວໂຫຼດ / ອັບເດດຄ່າເລີ່ມຕົ້ນ
ດາວໂຫຼດ ຫຼື ອັບເດດຊຸດໂມເດວທີ່ນັກພັດທະນາ darktable ແນະນຳໃຫ້ເປັນຄ່າເລີ່ມຕົ້ນສຳລັບແຕ່ລະໜ້າທີ່. ມີປະໂຫຍດສຳລັບການເລີ່ມຕົ້ນຢ່າງໄວວາເມື່ອຕິດຕັ້ງໃໝ່, ແລະ ເພື່ອດຶງເອົາເວີຊັນໃໝ່ຂອງໂມເດວເຫຼົ່ານັ້ນທີ່ຄັງເກັບໄດ້ເຜີຍແຜ່.
ດາວໂຫຼດ / ອັບເດດອັນທີ່ເລືອກ
ດາວໂຫຼດ ຫຼື ອັບເດດໂມເດວທີ່ຖືກໝາຍໃນກ່ອງໝາຍ select. ໃຊ້ສິ່ງນີ້ເມື່ອເຈົ້າໄດ້ໝາຍບາງໂມເດວໃນລາຍການ ແລະ ຕ້ອງການຈັດການສະເພາະໂມເດວເຫຼົ່ານັ້ນ.
ນຳເຂົ້າຈາກໄຟລ໌…
ຕິດຕັ້ງໂມເດວຈາກໄຟລ໌ເກັບ .dtmodel ໃນເຄື່ອງ. ຕົວເລືອກໄຟລ໌ຈະຖືກຄັດກອງໃຫ້ເຫັນແຕ່ *.dtmodel; ເມື່ອນຳເຂົ້າແລ້ວ, ໂມເດວຈະພ້ອມໃຊ້ງານທັນທີ. ໃຊ້ສິ່ງນີ້ສຳລັບໂມເດວທີ່ທ່ານໄດ້ຮັບມາໂດຍກົງ, ໂມເດວທີ່ທ່ານສ້າງເອງ, ຫຼື ທາງເລືອກເພີ່ມເຕີມຕໍ່ໜ້າທີ່ຈາກຄັງເກັບ darktable-ai – ລາຍຊື່ໃນແອັບຈະສະແດງພຽງໜຶ່ງ ຫຼື ສອງໂມເດວຕໍ່ໜ້າທີ່, ແຕ່ໃນຄັງເກັບຂໍ້ມູນອາດຈະມີການເຜີຍແຜ່ທາງເລືອກເພີ່ມເຕີມສຳລັບໜ້າທີ່ດຽວກັນ (ໂມເດວ denoise ທີ່ແຕກຕ່າງກັນເຊິ່ງຝຶກດ້ວຍຊຸດຂໍ້ມູນອື່ນ, ໂຄງສ້າງການແຍກສ່ວນທາງເລືອກ ແລະ ອື່ນໆ). ດາວໂຫຼດ .dtmodel ຈາກສ່ວນ releases ໃນ GitHub ຂອງຄັງເກັບຂໍ້ມູນ ແລະ ນຳເຂົ້າມັນຢູ່ທີ່ນີ້.
ລຶບອັນທີ່ເລືອກ
ລຶບໂມເດວທີ່ຖືກໝາຍໃນກ່ອງໝາຍ select ອອກຈາກດິສກ໌. ໂມເດວທີ່ແຖມມານຳ darktable ບໍ່ສາມາດລຶບອອກໄດ້.

ການດາວໂຫຼດຈະເຮັດວຽກຢູ່ເບື້ອງຫຼັງພ້ອມກັບໜ້າຕ່າງສະແດງຄວາມຄືບໜ້າ ແລະ ສາມາດຍົກເລີກໄດ້. ການດາວໂຫຼດທີ່ຫຼົ້ມເຫຼວຈະຖືກລາຍງານ ແລະ ໂມເດວທີ່ກ່ຽວຂ້ອງຈະຍັງຄົງຢູ່ໃນສະຖານະເດີມ.
