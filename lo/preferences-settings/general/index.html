      ພາສາຂອງອິນເຕີເຟດ
      ຕັ້ງພາສາຂອງໜ້າຕ່າງການໃຊ້ງານ. ນີ້ລວມເຖິງຕົວເລືອກໃນການໃຊ້ຕົວພິມໃຫຍ່ແບບປະໂຫຍກ (en@truecase) ສຳລັບພາສາອັງກິດ. ຄ່າເລີ່ມຕົ້ນຂອງລະບົບຈະຖືກໝາຍດ້ວຍ * (ຕ້ອງໄດ້ເລີ່ມຕົ້ນໃໝ່)
      ທິມ (Theme)
      ຕັ້ງທິມສຳລັບໜ້າຕ່າງການໃຊ້ງານ. ນອກເໜືອຈາກຄວາມສວຍງາມແລ້ວ, ສີອິນເຕີເຟດທີ່ແນະນຳສຳລັບການປະເມີນສີແມ່ນສີເທົາກາງ (middle gray). ການຮັບຮູ້ທາງສາຍຕາໄດ້ຮັບຜົນກະທົບຈາກຄວາມສະຫວ່າງຂອງສະພາບແວດລ້ອມ, ແລະ ຄວາມສະຫວ່າງຂອງອິນເຕີເຟດທີ່ຕ່ຳເກີນໄປອາດເຮັດໃຫ້ເກີດການຮັບຮູ້ທີ່ຜິດພ້ຽນ. ການໃຊ້ທິມທີ່ມືດຫຼາຍໃນການຕົບແຕ່ງຮູບພາບອາດນຳໄປສູ່ການປັບແຕ່ງທີ່ເກີນພໍດີ (ໃຊ້ contrast ແລະ saturation ຫຼາຍເກີນໄປ) ແລະ ເຮັດໃຫ້ຮູບພາບມືດເກີນໄປເມື່ອສັ່ງພິມ. ດັ່ງນັ້ນ, ຈຶ່ງຂໍແນະນຳຢ່າງຍິ່ງໃຫ້ໃຊ້ທິມ “grey” (ສີເທົາ) ສຳລັບການປັບແຕ່ງ ເພາະພວກມັນຖືກອອກແບບມາໃຫ້ມີຄວາມສະຫວ່າງໃກ້ຄຽງກັບສີເທົາກາງ. ສຳລັບຜູ້ທີ່ມີຄວາມຫຍຸ້ງຍາກໃນການອ່ານຂໍ້ຄວາມໃນທິມມາດຕະຖານ, darktable ກໍມີທິມ “highcontrast” (ຄວາມຕ່າງສີສູງ) ສອງແບບທີ່ມີຂໍ້ຄວາມສີຂາວເທິງພື້ນຫຼັງມືດ, ແຕ່ຂໍ້ຄວນລະວັງທີ່ກ່າວມາຂ້າງເທິງນັ້ນກໍຍັງມີຜົນຢູ່ຖ້າເຈົ້າເລືອກໃຊ້ພວກມັນ (ຄ່າເລີ່ມຕົ້ນແມ່ນ “darktable-elegant-grey”).

      Some elements of a theme are customizable by these additional preferences:

      condensed module controls
      When enabled, controls in modules are made smaller and spacing between them is reduced (default off).
      rounded module headers
      When enabled, one corner (the corner furthest from the application’s edge) of each module’s header is rounded (default off).
      focused module border
      When a color is selected, the currently focused processing module has a border of the selected color (default none).
      expanded module border
      When a color is selected, each expanded processing module has a border of the selected color (default none). If expand a single processing module at a time is enabled, then expanded module border has no effect as the expanded module is also the focussed module.
      accent color
      When a color is selected, the on/off button of a module is tinted with the selected color (default none).
      ໃຊ້ຂະໜາດຕົວອັກສອນຂອງລະບົບ
      ເລືອກຕົວເລືອກນີ້ເພື່ອໃຊ້ຂະໜາດຕົວອັກສອນຕາມທີ່ລະບົບຂອງເຈົ້າກຳນົດໄວ້. ຖ້າບໍ່ເລືອກ, ເຈົ້າສາມາດປ້ອນຂະໜາດຕົວອັກສອນເອງໃນກ່ອງດ້ານລຸ່ມ (ຄ່າເລີ່ມຕົ້ນແມ່ນເປີດ).
      ຂະໜາດຕົວອັກສອນເປັນພອຍ (points)
      ຖ້າຕົວເລືອກ “ໃຊ້ຂະໜາດຕົວອັກສອນຂອງລະບົບ” ຖືກປິດ, ໃຫ້ປ້ອນຂະໜາດຕົວອັກສອນ (ເປັນພອຍ) ທີ່ຕ້ອງການໃຫ້ darktable ໃຊ້. ຂະໜາດຕົວອັກສອນຈະປ່ຽນແປງທັນທີ.
      DPI ຂອງການຄວບຄຸມ GUI ແລະ ຂໍ້ຄວາມ
      ປັບຄວາມລະອຽດ GUI ໂດຍລວມເພື່ອປ່ຽນຂະໜາດຂອງການຄວບຄຸມ, ປຸ່ມ, ປ້າຍຊື່ ແລະ ອື່ນໆ. ເພີ່ມຂຶ້ນເພື່ອໃຫ້ GUI ໃຫຍ່ຂຶ້ນ, ຫຼຸດລົງເພື່ອໃຫ້ສະແດງເນື້ອໃນໄດ້ຫຼາຍຂຶ້ນໃນໜ້າຕ່າງ. ຕັ້ງເປັນ -1 ເພື່ອໃຊ້ຄວາມລະອຽດຕາມທີ່ລະບົບກຳນົດ. ຄ່າເລີ່ມຕົ້ນແມ່ນ 96 DPI ໃນລະບົບສ່ວນໃຫຍ່ (ຕ້ອງໄດ້ເລີ່ມຕົ້ນໃໝ່).
      ລ້າງຄ່າແຖບມຸມມອງ
      ລຳດັບ ແລະ ການສະແດງຜົນຂອງໂມດູນເຄື່ອງມືສາມາດປ່ຽນແປງໄດ້ດ້ວຍຕົນເອງໂດຍຜູ້ໃຊ້ (ເບິ່ງ ພາບລວມຂອງໂມດູນ). ຄລິກປຸ່ມນີ້ເພື່ອຕັ້ງຄ່າຄືນເປັນຄ່າເລີ່ມຕົ້ນ.

      #ການປັບແຕ່ງທິມດ້ວຍ CSS

      ນອກຈາກການເລືອກທິມທີ່ມີມາກັບລະບົບແລ້ວ, ເຈົ້າຍັງສາມາດປັບແຕ່ງ CSS ເພີ່ມເຕີມດ້ວຍຕົນເອງເພື່ອປັບປ່ຽນຮູບລັກສະນະຂອງ darktable ໄດ້.

      ສ້າງທິມທີ່ກຳນົດເອງ
      ຖ້າເຈົ້າຕ້ອງການປ່ຽນແປງ UI ຂອງ darktable ເປັນຈຳນວນຫຼາຍ, ເຈົ້າອາດຈະຕ້ອງການສ້າງທິມຂອງຕົນເອງ (ໃນໄຟລ໌ .css) ແລະ ນຳໄປວາງໄວ້ໃນໂຟນເດີ themes ໃນ ໄດເຣັກທໍຣີການຕັ້ງຄ່າ ຂອງ darktable. ທິມໃໝ່ຂອງເຈົ້າຈະປາກົດໃນລາຍການເລືອກ theme ໂດຍອັດຕະໂນມັດໃນຄັ້ງຕໍ່ໄປທີ່ເຈົ້າເລີ່ມຕົ້ນ darktable ໃໝ່.

      ກະລຸນາຮັບຊາບວ່າໂຄງສ້າງ CSS ພາຍໃນຂອງ darktable ມີການປ່ຽນແປງເລື້ອຍໆ ແລະ ເຈົ້າອາດຈະຕ້ອງປັບປຸງທິມຂອງເຈົ້າຢ່າງຫຼວງຫຼາຍເມື່ອ darktable ເວີຊັນໃໝ່ເຜີຍແຜ່. ດ້ວຍເຫດຜົນນີ້, ພວກເຮົາຈຶ່ງບໍ່ແນະນຳໃຫ້ສ້າງທິມທີ່ຊັບຊ້ອນ ເວັ້ນເສຍແຕ່ເຈົ້າມີເວລາໃນການເບິ່ງແຍງຮັກສາມັນຢ່າງຕໍ່ເນື່ອງ. ຖ້າທິມຂອງເຈົ້າໂຫຼດທິມອື່ນໆຂອງ darktable ໂດຍໃຊ້ຄຳສັ່ງ @import url, ໝາຍເຫດວ່າໄຟລ໌ CSS ຂອງເຈົ້າອາດຈະບໍ່ສາມາດໃຊ້ຂ້າມເຄື່ອງໄດ້ (ເພາະ @import url ໃຊ້ເສັ້ນທາງແບບສຳພັດ ແລະ ສະຖານທີ່ເກັບທິມອາດຈະແຕກຕ່າງກັນໃນແຕ່ລະລະບົບ).

      ສ້າງການປັບແຕ່ງທິມ
      ມີຊ່ອງຂໍ້ຄວາມໃຫ້ຢູ່ດ້ານລຸ່ມຂອງແທັບທົ່ວໄປ ເຊິ່ງເຈົ້າສາມາດປ້ອນການປັບແຕ່ງ CSS ຂອງເຈົ້າເອງໄດ້. ເມື່ອໃຊ້ຕົວເລືອກນີ້, darktable ຈະໂຫລດທິມທີ່ເຈົ້າເລືອກ (ທິມ “ພື້ນຖານ”, ທີ່ເລືອກໃນລາຍການເລືອກ ທິມ) ກ່ອນ ແລ້ວຈຶ່ງນຳໃຊ້ CSS ທີ່ເຈົ້າປັບແຕ່ງເອງທັບລົງໄປ. ນີ້ໝາຍຄວາມວ່າ ເຈົ້າສາມາດປ່ຽນແປງຮູບລັກສະນະເລັກໆນ້ອຍໆໄດ້ຢ່າງງ່າຍດາຍ, ໃນຂະນະທີ່ຍັງຄົງທັນສະໄໝກັບການປ່ຽນແປງຫຼັກຂອງທິມ ເມື່ອມີ darktable ເວີຊັນໃໝ່ອອກມາ. ມັນຍັງໝາຍຄວາມວ່າ ໂດຍປົກກະຕິແລ້ວເຈົ້າສາມາດປ່ຽນທິມພື້ນຖານໄດ້ ໂດຍບໍ່ສົ່ງຜົນກະທົບຕໍ່ການປັບແຕ່ງ CSS ຂອງເຈົ້າ.

      ເມື່ອເຈົ້າປ້ອນ CSS ສຳເລັດແລ້ວ, ໃຫ້ຄລິກປຸ່ມ “save CSS and apply”. ນີ້ຈະບັນທຶກ CSS ຂອງເຈົ້າລົງໃນໄຟລ໌ user.css ໃນ ໄດເຣັກທໍຣີການຕັ້ງຄ່າ ຂອງ darktable ແລະ ຈະມີຜົນກັບເຊດຊັນ (session) ຂອງ darktable ປັດຈຸບັນທັນທີ.

      ຖ້າເຈົ້າພົບບັນຫາຫຼັງຈາກປັບໃຊ້ CSS, ເຈົ້າສາມາດຍົກເລີກການໝາຍໃນກ່ອງ “modify selected theme with CSS tweaks below” ເພື່ອກັບໄປໃຊ້ຄ່າເດີມ. ນີ້ຈະຄືນຄ່າທິມຫຼັກທັນທີ ແຕ່ຍັງຄົງຂໍ້ຄວາມທີ່ເຈົ້າປັບແຕ່ງໄວ້ໃນຕົວແກ້ໄຂເພື່ອໃຫ້ເຈົ້າສາມາດແກ້ໄຂໃໝ່ ແລະ ລອງອີກຄັ້ງ. ພຽງແຕ່ກົດ “save CSS and apply” ອີກຄັ້ງເມື່ອເຈົ້າພ້ອມ. ນີ້ຈະໝາຍກ່ອງດັ່ງກ່າວຄືນໂດຍອັດຕະໂນມັດ ແລະ ປັບໃຊ້ CSS ໃໝ່.

      ໝາຍເຫດ: ຖ້າເຈົ້າພົບບັນຫາໃນຂະນະທີ່ໃຊ້ CSS ທີ່ປັບແຕ່ງເອງ, ກະລຸນາລອງໃໝ່ໂດຍການຍົກເລີກຕົວເລືອກ “modify selected theme with CSS tweaks below” ເພື່ອໃຫ້ແນ່ໃຈວ່າບັນຫານັ້ນບໍ່ໄດ້ເກີດມາຈາກການປ່ຽນແປງຂອງເຈົ້າ.

      #ທຳຄວາມເຂົ້າໃຈກ່ຽວກັບທິມຂອງ darktable

      ທິມທັງໝົດຂອງ darktable ຈະຢູ່ໃນຮູບແບບໄຟລ໌ CSS ທີ່ $DARKTABLE/share/darktable/themes/ (ເຊິ່ງ $DARKTABLE ແມ່ນໄດເຣັກທໍຣີທີ່ຕິດຕັ້ງ darktable). ທິມ darktable.css ບັນຈຸໂຄ້ດສ່ວນໃຫຍ່ທີ່ໃຊ້ຄວບຄຸມຮູບລັກສະນະຂອງ darktable. ຍັງມີທິມອື່ນໆອີກຫຼາຍແບບ ແຕ່ສ່ວນໃຫຍ່ຈະໃຊ້ darktable.css ເປັນພື້ນຖານ (ໂດຍການນຳເຂົ້າ darktable.css ດ້ວຍຄຳສັ່ງ @import url).

      ຖ້າເຈົ້າເລືອກທີ່ຈະສ້າງໄຟລ໌ທິມເອງ, ຂໍແນະນຳໃຫ້ເຮັດໃນຮູບແບບດຽວກັນ – ຄືການນຳເຂົ້າໄຟລ໌ທິມທີ່ມີຢູ່ແລ້ວຂອງ darktable ໂດຍໃຊ້ @import url (ຄຳສັ່ງນີ້ຕ້ອງການເສັ້ນທາງແບບສຳພັດ) ແລ້ວຈຶ່ງປັບແຕ່ງທັບລົງໄປ. ເຈົ້າບໍ່ຈຳເປັນຕ້ອງເຮັດແບບນີ້ເມື່ອໃຊ້ກ່ອງຂໍ້ຄວາມ CSS ໃນໜ້າຕ່າງຄວາມມັກ – ເພາະການໃຊ້ @import url ໃນກ່ອງຂໍ້ຄວາມປັບແຕ່ງ CSS ຈະເຮັດວຽກບໍ່ຖືກຕ້ອງ.

      ທິມຕ່າງໆໃຊ້ຫຼັກການພື້ນຖານຂອງ CSS ແບບດຽວກັບໃນເວັບບຣາວເຊີ (ໂດຍມີຂໍ້ຍົກເວັ້ນບາງຢ່າງ – ເບິ່ງລາຍລະອຽດທີ່ Gtk documentation):

      • ຄຸນສົມບັດສະໄຕລ໌ສ່ວນໃຫຍ່ຈະຖືກກຳນົດໃຫ້ກັບກຸ່ມກວ້າງໆຂອງອົງປະກອບ UI, ຕົວຢ່າງ: ປຸ່ມ Gtk ແລະ ຊ່ອງປ້ອນຂໍ້ຄວາມ

      • ຕໍ່ມາ, ກຸ່ມອົງປະກອບ UI ທີ່ເປັນຂອງ darktable ໂດຍສະເພາະຈະຖືກຕັ້ງ ຊື່ຄລາດ (class names) ເພື່ອໃຫ້ສາມາດກຳນົດສະໄຕລ໌ເປັນກຸ່ມໄດ້

      • ສຸດທ້າຍ, ອົງປະກອບ UI ບາງຢ່າງທີ່ເປັນເອກະລັກຈະຖືກກຳນົດ CSS id ເພື່ອໃຫ້ສາມາດກຳນົດສະໄຕລ໌ແຍກຕ່າງຫາກໄດ້

      ພວກເຮົາສະໜັບສະໜູນໃຫ້ເຈົ້າລອງສຶກສາທິມທີ່ມີຢູ່ແລ້ວ (ໂດຍສະເພາະ darktable.css ເຊິ່ງມີຄຳອະທິບາຍໄວ້ດີຫຼາຍ) ແລະ ໃຊ້ເຄື່ອງມື Gtk Inspector ເພື່ອຄົ້ນຫາວິທີການເລືອກອົງປະກອບ UI ສະເພາະ (ຫຼື ກຸ່ມຂອງອົງປະກອບ) ທີ່ເຈົ້າຕ້ອງການປ່ຽນແປງ. ເຈົ້າອາດຈະຕ້ອງໄດ້ທົດລອງບາງຢ່າງ.

      ກະລຸນາໝາຍເຫດວ່າທິມຂອງ darktable ຈະເປັນລະດັບສີເທົາໂດຍມາດຕະຖານ ເພື່ອບໍ່ໃຫ້ຜູ້ໃຊ້ຖືກລົບກວນໂດຍສີທີ່ເຂັ້ມເກີນໄປໃນຂະນະທີ່ແກ້ໄຂຮູບພາບ. ເຈົ້າໄດ້ຮັບຄຳແນະນຳໃຫ້ຮັກສາແນວທາງນີ້ໃນທິມຂອງເຈົ້າເອງ ແລະ ພະຍາຍາມໃຫ້ລະດັບສີໂດຍສະເລ່ຍໃກ້ຄຽງກັບສີເທົາກາງທີ່ສຸດ. ນອກຈາກນີ້, ຂໍແນະນຳໃຫ້ເຈົ້າກວດສອບ CSS ຂອງເຈົ້າທຸກຄັ້ງທີ່ມີການອັບເດດ darktable ເພື່ອໃຫ້ແນ່ໃຈວ່າການປ່ຽນແປງໃນແອັບພລິເຄຊັນຈະບໍ່ສົ່ງຜົນກະທົບຕໍ່ສິ່ງທີ່ເຈົ້າປັບແຕ່ງໄວ້.
