                                      Sessione

                                      Impostare un codice sessione per permettere la creazione di un nuovo rullino.

                                      Una sessione è una sequenza di scatti effettuati in tethering (scatto remoto) che viene inserita in un singolo rullino. Aprire una nuova sessione significa creare un nuovo rullino.

                                      Questo modulo sessione permette di impostare un codice, che può essere usato per creare un nuovo rullino. Si veda preferences > import > session options per dettagli riguardo la creazione di un nuovo rullino usando la variabile $(JOBCODE) nel modulo sessione.
