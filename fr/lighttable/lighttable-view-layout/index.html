Disposition de la vue Table lumineuse

🔗Panneau gauche

De haut en bas :

Importer
Importer des images depuis le système de fichiers ou depuis un boîtier connecté.
Collections
Filtrer les images affichées dans le panneau central de la Table lumineuse – aussi utilisé pour contrôler les images affichées dans les modules Pellicule et Chronologie.
Collections récentes
Afficher les collections d’images récemment utilisées.
Informations de l’image
Afficher les informations de l’image.
Installer les scripts Lua (optionnel)
Installer les scripts Lua.

🔗Panneau droit

De haut en bas :

Sélection
Sélectionner des images de la Table lumineuse en utilisant des critères simples.
Actions sur la sélection
Effectuer des actions sur les images sélectionnées.
Développement
Manipuler le développement des images sélectionnées.
Styles
Stocker l’historique d’une image en tant que style nommé et l’appliquer à d’autres images.

Éditeur de métadonnées  : Éditer les métadonnées des images sélectionnées.

Mots-clés
Étiqueter par mots-clés les images sélectionnées.
Géolocalisation
Importer et appliquer les données de suivi GPX aux images sélectionnées.
Exporter
Exporter les images sélectionnées vers des fichiers locaux ou des services externes.
neural restore
Apply AI-powered raw denoise, RGB denoise, or upscaling to selected images.

🔗Panneau inférieur

De gauche à droite :

Notations par étoiles
Appliquer des notations par étoiles aux images.
étiquettes de couleur
Appliquer des étiquettes de couleur aux images. Faites un clic droit pour attribuer un nom descriptif à n’importe quelle étiquette de couleur. La description s’affiche uniquement dans l’info-bulle qui apparaît lorsque vous survolez l’étiquette de couleur (et non dans les filtres de collection ou tout autre élément de l’interface utilisateur).
Sélecteur du mode
Choisir un mode de la Table lumineuse.
zoom
Adjust the number of thumbnails displayed in each row of the file manager view.
Mettre en surbrillance les zones nettes
Mettre en surbrillance les zones nettes de l’image (les zones de mise au point).
Définir le profil écran
Choisir le profil écran de votre (vos) moniteur(s).
