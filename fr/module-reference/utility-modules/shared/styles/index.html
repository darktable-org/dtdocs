Styles

Table des matières
  • Contrôles du module
  • Préférences

Des images étant sélectionnées, créer à partir de leur Historique des styles nommés ou leur appliquer des styles.

Les styles peuvent être créés dans ce panneau ou dans le module Historique de la Chambre noire.

Une liste de tous les styles disponibles s’affiche dans le module. Un champ de recherche au-dessus de la liste vous permet de localiser un style par son nom ou sa description. Ce module permet également d’éditer et de supprimer des styles.

Double-cliquez sur un nom de style pour appliquer ce style à toutes les images sélectionnées. Lorsque vous êtes dans les vues Table lumineuse ou Chambre noire, un style peut également être appliqué aux images sélectionnées en appuyant sur une touche de raccourci qui lui a été attribuée (voir Préférences > Raccourcis) .

Survolez le nom du style avec votre souris pour afficher un aperçu de la première image sélectionnée avec ce style appliqué.

Supprimez tous les styles en cliquant sur le bouton Réinitialisation du module.

Veuillez noter que les styles incluent également l’état actif de chaque module. Vous pouvez utiliser ceci pour créer vos propres paramètres par défaut – vous pourrez ensuite les activer à la demande. Définissez simplement les valeurs par défaut souhaitées pour chaque module, désactivez le module et enregistrez le style.

Un grand choix de styles « d’appareils » est fourni avec Darktable. Ces styles sont conçus pour se rapprocher de l’apparence du JPEG des appareils pour les modèles pris en charge et peuvent être trouvés dans ce module sous le groupe de styles d’appareils « Darktable ». Vous pouvez appliquer automatiquement ces styles lors de l’importation à l’aide du script Lua compagnon official/appareil photo.

#Contrôles du module

Cacher l’aperçu
Utilisez cette case à cocher pour masquer entièrement l’aperçu de l’info-bulle. Cela peut être utile sur les ordinateurs plus lents, sur lesquels le rendu de l’aperçu peut prendre plus de temps.
Cloner l’image et appliquer le style
Lors de l’application d’un style aux images sélectionnées, cochez cette case pour créer un clone de chaque image avant d’appliquer le style choisi à ce clone. Désactivez cette option pour appliquer le style choisi directement aux images sélectionnées. Attention, dans ce cas, tout historique existant est écrasé (selon le mode choisi – voir ci-dessous) et ne peut pas être récupéré.
Mode
Comme dans le module Historique, la liste déroulante vous propose Empiler le style à l’historique actuel ou Écraser l’historique de l’image cible.
Créer…
Créer un ou des nouveaux styles à l’aide de l’historique des images sélectionnées. Pour chaque image sélectionnée, une fenêtre de création de style s’affiche. Vous devez fournir un nom unique pour chaque nouveau style et vous pouvez également ajouter une description facultative.

Vous aurez la possibilité de sélectionner les éléments de l’historique que vous souhaitez inclure dans le style créé. Pour n’importe quel module, vous pouvez également choisir de Réinitialiser les paramètres de ce module – cela aura pour effet d’inclure le module dans le style, mais avec tous les contrôles réglés à leur état initial (par défaut) (comme si vous aviez cliqué sur le bouton Réinitialiser du module).

Le panneau prend en charge une vue hiérarchique, ce qui signifie que vous pouvez créer des catégories à l’aide du symbole barre verticale « | » comme séparateur. Par exemple, « Imprimer|Courbe des tonalités +0,5 IL » créera une catégorie Imprimer avec un style « Courbe des tonalités+0,5 IL » en dessous.

Les masques des modules d’un style sont enregistrés avec le style, y compris leurs formes, et sont reconstruits sur chaque image à laquelle le style est appliqué (voir Préréglages et masques). Les Objets IA qui sont stockés sous forme de pixels appartiennent à une image et sont exclus du style : Darktable demande d’abord confirmation, en nommant les modules concernés. Pour conserver un objet IA dans un style, créez-le avec Appliquer comme chemins sélectionnés.

Vous pouvez annuler le processus de création en appuyant sur le bouton Annuler ou en appuyant sur la touche Échap de votre clavier.

Modifier
Sélectionnez « modifier » pour afficher une boîte de dialogue vous permettant de modifier un style existant. La partie supérieure de la boîte de dialogue présente les modules actuellement inclus dans le style, tandis que la partie inférieure affiche tous les modules disponibles dans la pile d’historique des images sources. Pour que ces derniers apparaissent, une image doit être sélectionnée ; si aucune image ou plusieurs images sont sélectionnées, aucune pile d’historique source ne sera proposée.
Vous pouvez ajouter ou supprimer des modules, ainsi que choisir ceux à mettre à jour depuis la pile d’historique source, en cochant les cases correspondantes.
Cochez l’option « dupliquer » si vous souhaitez créer un nouveau style au lieu d’écraser celui qui existe déjà ; vous devrez alors donner un nom unique à ce nouveau style.
Enlever
Supprime le style sélectionné, sans aucune invite.
Importer…
Importer un style précédemment enregistré. Les styles sont stockés sous forme de fichiers XML avec l’extension .dtstyle. Si un style du même nom existe déjà, il vous sera demandé si vous souhaitez l’écraser.
Exporter…
Enregistrer le style sélectionné sur le disque en tant que fichier .dtstyle. Cela permet aux styles d’être publiés et partagés avec d’autres utilisateurs.

#Préférences

L’option « Préférences… » du menu des préréglages vous permet de modifier les paramètres suivants :

Taille des prévisualisations
Définissez la taille de l’aperçu sur l’info-bulle. Les options disponibles sont : défaut et grande.
