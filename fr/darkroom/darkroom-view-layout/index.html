Disposition de la vue Chambre noire

🔗Panneau gauche

De haut en bas :

Navigation
Naviguer dans la vue centrale et la zoomer.
Instantanés
Prendre et afficher des instantanés pour les comparer avec le développement actuel.
Gestion des clones
Afficher et gérer les clones.
Pipette de couleur
Sélectionner et afficher les informations de couleur provenant de parties de l’image.
Mots-clés
Gérer les mots-clés.
Informations de l’image
Afficher des informations de l’image actuelle.
Gestion des masques
Afficher et modifier les formes dessinées.
Exporter
Exporter les images sélectionnées vers des fichiers locaux ou des services externes.
Restauration neuronale
Appliquer une restauration basée sur l’IA aux images sélectionnées : débruitage RAW, débruitage RVB ou mise à l’échelle.

🔗Panneau droit

De haut en bas :

Scopes
Une représentation graphique des niveaux de luminosité et des couleurs de l’image. Ce module peut être déplacé vers le panneau de gauche si vous le souhaitez (voir Préférences > Divers > Position du module Scopes).
Groupes de modules
Sélectionnez des groupes de modules (si activé).
Rechercher un module
Rechercher un module (si activé).
Modules de traitement
Les modules utilisés pour traiter une image.
Ordre des modules
Choisir l’ordre dans lequel les modules de traitement sont exécutés dans le pipeline graphique.

🔗Panneau inférieur

De gauche à droite :

Préréglages
Menu d’accès rapide aux préréglages des modules. Vous pouvez gérer le contenu de ce menu en sélectionnant Gérer la liste des préréglages…
Styles
Menu d’accès rapide aux styles. Survolez un nom de style avec votre souris pour afficher un aperçu de l’image actuelle de la Chambre noire avec le style sélectionné.
seconde fenêtre de la chambre noire
Permet à l’utilisateur d’afficher une deuxième image dans une fenêtre séparée. Par défaut, la deuxième fenêtre affiche le même contenu que la vue principale. Lorsqu’une image est « épinglée » dans la deuxième fenêtre, elle restera inchangée lors des modifications dans les modules, de la navigation dans la pile d’historique ou de l’ouverture d’une image différente dans la vue principale. Ceci est particulièrement utile sur les grands écrans et les configurations multi-écrans.
Basculer le mode zones nettes
Activer/désactiver le mode détection des zones nettes.
Conditions d’évaluation des couleurs
Activer/désactiver la vue Conditions d’évaluation des couleurs ISO12646.
traitement de haute qualité
Activer/désactiver le traitement de haute qualité.
Avertissement de surexposition RAW
Activer/désactiver les indicateurs de zones surexposées RAW (clic-droit pour les options).
Avertissement de troncature
Activer/désactiver les avertissements de troncature (clic-droit pour les options).
Épreuvage écran
Activer/désactiver les superpositions de l’épreuvage écran (clic-droit pour les options).
Vérification de gamut
Activer/désactiver la vérification de gamut (clic-droit pour les options).
Guides & superpositions
Cliquez avec le bouton gauche pour activer/désactiver les superpositions de guide global et cliquez avec le bouton droit pour modifier les paramètres du guide, y compris la couleur de tous les tracés sur l’image (masques, guides de recadrage, etc.)

Vous pouvez aussi activer le module Pellicule en bas de l’écran pour vous permettre de sélectionner et d’interagir avec la collection actuellement sélectionnée dans la vue Table lumineuse.
